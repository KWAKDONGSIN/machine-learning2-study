연습 문제 — 그래프와 개념으로 풀어 봐요

문제 1. 아래 이름 없는 세 그래프의 이름을 순서대로 쓰세요.

정답 보기

① Tanh (−1~1, 원점 통과), ② ReLU (음수는 0, 위로 끝없이 올라감), ③ Sigmoid (0~1, x=0에서 0.5)예요.

문제 2. 다음 중 Sigmoid에 대한 설명으로 틀린 것은?

  • ① 출력 범위가 (0, 1)이다
  • ② 도함수의 최대값이 0.25이다
  • ③ 양끝에서 기울기가 0에 가까워진다
  • ④ 음수 입력에서는 항상 0을 출력한다
정답 보기

④예요. 음수 입력에서 0을 내는 것은 ReLU이고, Sigmoid는 음수 입력에도 0보다 큰 작은 값(예 σ(−2) ≈ 0.12)을 내요.

문제 3. 기울기 소실이 가장 심하게 나타나기 쉬운 은닉층 구성은?

  • ① 10층 ReLU
  • ② 10층 Sigmoid
  • ③ 10층 Leaky ReLU
  • ④ 2층 ReLU
정답 보기

②예요. Sigmoid는 기울기가 최대 0.25라서 10층이면 0.25¹⁰ ≈ 10⁻⁶으로 줄어들어요. ReLU 계열은 양수 구간 기울기가 1이에요.

문제 4. 정답이 "고양이, 개, 새" 중 하나인 3개 클래스 분류의 출력층 구성은?

  • ① 뉴런 1개, Sigmoid, Binary Cross-Entropy
  • ② 뉴런 3개, Softmax, Categorical Cross-Entropy
  • ③ 뉴런 3개, Linear, MSE
  • ④ 뉴런 3개, ReLU, Binary Cross-Entropy
정답 보기

②예요. 정답이 하나인 다중 클래스는 클래스 수만큼 뉴런을 두고 Softmax와 Categorical Cross-Entropy를 써요.

문제 5. "활성화 함수가 필요한 이유를 서술하시오"에 대한 모범 답안을 써 보세요.

모범 답안 보기

활성화 함수가 없으면 가중합(선형)을 여러 층 합성해도 결과가 하나의 선형 함수 W′x + b′가 되어, 은닉층을 쌓아도 선형 분류기 하나와 다름없다. 은닉층 사이에 비선형 활성화 함수를 넣어야 층을 쌓을수록 복잡한 비선형 경계를 표현할 수 있고, 활성화 함수는 기울기 흐름을 정해 학습의 안정성과 속도에도 영향을 준다.
