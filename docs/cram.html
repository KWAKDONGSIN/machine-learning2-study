정수 계산 3종

  1. 파라미터 수 = 입력 × 출력 + 출력 (층마다 구해서 더하기, Flatten · Dropout은 0). 예: 784→256→10 = (784×256+256) + (256×10+10) = 200,960 + 2,570 = 203,530. 4→5→3 = 25 + 18 = 43.
  2. step / epoch = ⌈샘플 수 ÷ batch_size⌉ (나머지가 있으면 무조건 올림). 예: 55,000 ÷ 128 = 429.69 → 430. 20,000 ÷ 256 = 78.125 → 79. 전체 갱신 = step × epoch.
  3. 혼동행렬 Precision = TP/(TP+FP), Recall = TP/(TP+FN), F1 = 2PR/(P+R), Accuracy = (TP+TN)/전체. 예: TP=30, FP=10, FN=20, TN=140이면 P = 30/40 = 0.75, R = 30/50 = 0.6, Acc = 170/200 = 0.85. 3×3은 Precision이 열 합계, Recall이 행 합계로 나눠요.

EarlyStopping 한 줄: 멈추는 epoch = 최고 epoch + patience. 최고 7, patience 3이면 10 epoch 끝에 멈추고, restore_best_weights=True면 epoch 7의 가중치예요.

꼭 외울 20줄

  1. 출력층 세트 — 이진은 뉴런 1 · sigmoid · BCE, 다중은 K · softmax · CE, 회귀는 1 · linear(없음) · MSE.
  2. 멀티라벨(여러 개 정답)은 K개 sigmoid + BCE예요. 다중 클래스(하나만 정답)와 헷갈리지 마세요.
  3. Softmax 출력은 전부 0~1이고 합이 1이에요.
  4. Softmax는 모든 입력에 같은 상수를 더해도 결과가 불변이고, 입력의 순위(argmax)도 유지돼요.
  5. Cross-Entropy는 정답 클래스의 확률만 채점하고, 자신 있게 틀릴수록(정답 확률이 0에 가까울수록) 벌점이 급격히 커져요.
  6. Softmax + CE의 기울기는 (예측 − 정답)이에요.
  7. 학습률이 너무 크면 손실이 튀다 발산(NaN)하고, 너무 작으면 아주 느리게 줄어요.
  8. 활성화 함수가 없으면 층을 아무리 쌓아도 선형 ∘ 선형 = 선형이라 하나의 선형 모델과 같아요.
  9. 시그모이드는 σ′ ≤ 0.25라서 층을 거칠수록 기울기가 줄어 기울기 소실이 생겨요.
  10. ReLU는 음수 입력이 0이고 기울기도 0이라 한 번 죽은 뉴런은 학습이 안 되는 죽은 ReLU 위험이 있어요. 은닉층 기본값이에요.
  11. 암 검진은 놓침(FN)이 치명적이라 Recall, 스팸 차단은 정상 메일을 막는 FP가 아프니 Precision이에요.
  12. 정확도의 함정 — 양성이 10%뿐이면 "모두 음성"만 답해도 Accuracy 0.9인데 Recall은 0이에요.
  13. 임계값을 낮추면 Recall은 오르고 Precision은 내려가요. 높이면 반대예요.
  14. 역전파는 출력의 오차를 Chain Rule로 뒤에서 앞으로 전달해 각 가중치의 기울기를 구하는 것이고, 순전파는 입력에서 출력까지 계산하는 것이에요.
  15. L1은 가중치를 0으로 만들어 희소하게, L2는 가중치의 크기를 제한해요.
  16. Dropout은 학습 때만 뉴런을 무작위로 끄고, 추론 때는 전부 켜요. 과적합을 줄여요.
  17. 조기 종료는 검증 손실이 더 나아지지 않으면 멈추는 것이고, restore_best_weights=True면 최고 시점으로 되돌려요.
  18. 편향(bias)이 없으면 결정경계가 원점을 지나야 해요. 편향은 경계를 평행 이동시키고 뉴런마다 하나예요.
  19. 과적합은 학습은 잘하고 검증은 나쁜 상태이고, 곡선은 반드시 학습·검증 두 줄을 같이 봐요.
  20. val_loss는 확률의 품질(과신)까지 봐서 val_accuracy보다 과적합을 더 일찍 드러내요.

틀 1 — 현상 → 근거 → 처방 (예시 답)

문제: 학습 손실은 계속 줄지만 검증 손실은 epoch 6에서 최소가 된 뒤 다시 올라간다.

(1) 과적합이다. (2) 학습 손실은 계속 감소하는데 검증 손실은 epoch 6 이후 증가하고 두 곡선의 간격이 벌어진다. 모델이 학습 데이터를 외워 새로운 데이터에 일반화하지 못한다는 뜻이다. (3) 검증 손실이 최소인 epoch 6 부근에서 EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True)으로 멈추고, 추가로 Dropout, L2, 데이터 증강 · 추가, 은닉 유닛 축소를 쓴다.

틀 2 — 상황 → 출력층 · 지표 · 임계값 (예시 답)

문제: 환자가 10%인 암 검진 데이터로 양성/음성을 가르는 신경망.

(1) 이진 분류이므로 출력 뉴런 1개, Sigmoid, Binary Cross-Entropy를 쓴다. (2) 모두 음성이라 해도 정확도가 90%가 나오는 함정이 있어 정확도만으로는 부족하다. 암을 놓치는 FN이 치명적이므로 Recall을 우선하고 Precision과 혼동행렬을 함께 본다. (3) 임계값은 0.5보다 낮춰(예 0.3) 양성 판정을 늘려 Recall을 높인다. (4) 입력은 표준화하되 학습셋 통계로만 fit하여 누수를 막는다.

가리고 맞히기 15

1. 10클래스 정수 라벨(0~9) 분류의 compile 손실 문자열은?

'sparse_categorical_crossentropy'. 라벨이 정수면 sparse가 붙어요.

2. 라벨이 원-핫 벡터일 때 다중 분류 손실 문자열은?

'categorical_crossentropy'. 원-핫이면 sparse를 빼요.

3. 이진 분류 출력층을 Keras로 쓰면?

Dense(1, activation='sigmoid') + loss='binary_crossentropy'. 확률 하나만 내면 돼요.

4. 조기 종료 콜백 한 줄을 쓰면?

EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True). 볼 지표 · 기다릴 횟수 · 최고로 복원이에요.

5. 콜백을 학습에 연결하는 인자는?

fit(..., callbacks=[early_stop]). 콜백은 리스트로 넣어요.

6. 784→128→10 모델의 파라미터 수는?

101,770. (784×128+128) + (128×10+10) = 100,480 + 1,290이에요.

7. 샘플 20,000개, batch_size 256이면 1 epoch의 step 수는?

79. 78.125를 올림해요.

8. TP=30, FP=10, FN=20이면 Precision과 Recall은?

P = 30/40 = 0.75, R = 30/50 = 0.6. 분모가 각각 예측 양성, 실제 양성이에요.

9. 최고 epoch 7, patience 3이면 몇 epoch에서 멈추나?

10 epoch. 최고 epoch + patience예요.

10. 활성화 함수 없이 층만 쌓으면?

하나의 선형 모델과 같다. 선형 ∘ 선형 = 선형이기 때문이에요.

11. Softmax 입력 모두에 같은 상수를 더하면 출력은?

변하지 않는다. 상수가 분자와 분모에서 약분돼요.

12. 학습 손실은 ↓, 검증 손실은 ↑이면 진단과 처방은?

과적합. EarlyStopping, Dropout, L2, 데이터 증강으로 처방해요.

13. 손실이 튀다가 NaN이 되면?

학습률 과대(발산). 학습률을 10배 낮춰요.

14. 암 검진에서 우선할 지표는?

Recall. 환자를 놓치는 FN이 치명적이기 때문이에요.

15. Dropout은 언제 뉴런을 끄나?

학습 때만 끈다. 추론 때는 전부 켜요.
