머신러닝 큰 그림 — 지도학습, 샘플, 특성, 정답

한 줄 정의

머신러닝은 사람이 규칙을 직접 쓰는 대신, 데이터를 보여 주고 컴퓨터가 규칙(모델)을 스스로 찾게 하는 방법이에요. 진짜 목표는 처음 보는 새 데이터도 잘 맞히는 것(일반화)이에요.

데이터는 엑셀 표라고 생각하면 돼요. 표에서 쓰는 이름 몇 개만 알면 이 과목의 글이 훨씬 잘 읽혀요.

이름뜻식품 쪽 비유
샘플(sample)표의 한 행. 데이터 한 건시제품 1개
특성(feature)표의 한 열. 샘플을 설명하는 숫자당도, 염도, 수분 같은 성분표 항목
정답(label, y)맞히려는 값. "라벨" 또는 "타깃"이라고도 해요소비자 맛 평가 점수
입력(X)특성들을 모은 것. 대문자 X는 표 전체성분표 전체
예측값(ŷ)모델이 계산해 낸 값. 모자(^)가 있으면 예측이에요배합표로 예상한 점수

정답이 붙어 있느냐로 학습 방식이 갈려요. 이 한 문장이 핵심이에요.

방식정답하는 일예
지도학습있음입력 X에서 정답 y를 맞히는 규칙을 배워요스팸 분류, 집값 예측
비지도학습없음정답 없이 데이터의 모양(묶음)을 찾아요비슷한 고객끼리 묶기(군집)

지도학습은 다시 둘로 나뉘어요. 맞히려는 것이 범주면 분류, 숫자면 회귀예요. 교수님은 "분류는 피아노처럼 도레미파로 딱딱 끊어지고, 회귀는 바이올린처럼 이어지는 소리"라고 비유했어요.

비유 — 문제집

지도학습은 해설이 달린 문제집으로 공부하는 것이고, 비지도학습은 정답 없는 문제 더미를 비슷한 것끼리 분류해 보는 것이에요. 시험 점수 예측은 숫자라서 회귀, "합격이냐 아니냐"는 범주라서 분류예요.

마지막으로 헷갈리기 쉬운 쌍이 하나 있어요. 파라미터(매개변수)는 모델이 학습하면서 스스로 찾는 값(가중치 w, 편향 b)이고, 하이퍼파라미터는 학습을 시작하기 전에 사람이 정해 주는 값(학습률, epoch 수 등)이에요.

시험엔 이렇게 써요

지도학습은 입력 X와 정답 y가 함께 주어진 데이터로 X에서 y로 가는 관계를 학습하는 방식이고, 비지도학습은 정답 없이 데이터의 구조를 찾는 방식이다. 파라미터는 모델이 학습으로 갱신하는 값(가중치·편향)이고 하이퍼파라미터는 사람이 학습 전에 정하는 값(학습률·epoch 등)이다.

잠깐 확인 — 학생의 시험 점수 예측과 스팸 여부 판별은 각각 회귀일까요, 분류일까요?

점수는 숫자라서 회귀, 스팸 여부는 범주라서 분류예요.
