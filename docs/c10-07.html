분류 평가 — 정확도, 정밀도, 재현율 ★

분류 결과는 혼동행렬이라는 네 칸 표에 담아요. 행은 실제, 열은 예측이에요.

예측 양성예측 음성
실제 양성TP (맞게 양성)FN (놓쳤어요)
실제 음성FP (헛경보)TN (맞게 음성)

앞 글자 T/F는 예측이 맞았나 틀렸나, 뒤 글자 P/N은 모델이 뭐라고 했나예요. 세 지표는 분모만 다르니 분모를 먼저 보세요.

지표식분모가 뜻하는 것
정확도(Accuracy)(TP + TN) / 전체전체 샘플
정밀도(Precision)TP / (TP + FP)모델이 "양성"이라고 한 것
재현율(Recall)TP / (TP + FN)실제 양성

예를 들어 100명 중 TP = 8, FP = 2, FN = 4, TN = 86이면 정확도는 (8 + 86) / 100 = 0.94, 정밀도는 8 / (8 + 2) = 0.8, 재현율은 8 / (8 + 4) = 약 0.67이에요.

정확도의 함정도 꼭 알아 두세요. 환자가 10%뿐인 데이터에서 "모두 정상"이라고만 답해도 정확도는 90%예요. 하지만 환자를 한 명도 못 찾으니 재현율은 0이에요. 암 검진처럼 놓치면 큰일인 문제는 재현율, 스팸 차단처럼 정상 메일을 잘못 막으면 곤란한 문제는 정밀도를 더 봐요.

외우기 팁

정밀도는 "내가 한 말 중 맞은 비율"이라 분모가 모델의 양성 판정이고, 재현율은 "진짜 양성 중 찾아낸 비율"이라 분모가 실제 양성이에요. 분모가 FP를 포함하면 정밀도, FN을 포함하면 재현율이에요.

시험엔 이렇게 써요

정밀도는 TP / (TP + FP)로 양성 예측 중 실제 양성의 비율이고, 재현율은 TP / (TP + FN)로 실제 양성 중 찾아낸 비율이다. 불균형 데이터에서는 정확도만으로 모델을 판단하면 안 되며, 암 검진처럼 FN의 비용이 크면 재현율을 우선한다.

잠깐 확인 — TP = 3, FP = 1, FN = 3일 때 정밀도와 재현율은?

정밀도 3 / (3 + 1) = 0.75, 재현율 3 / (3 + 3) = 0.5예요.

머신러닝2에서는 이렇게 이어져요

5장이 이 표 전체를 다뤄요. 정수로 끝나는 계산, 3×3 혼동행렬에서 클래스 하나씩 계산하기, 오류 비용에 따른 지표 선택이 시험에 나오는 부분이에요. 5장 계산 연습이 가장 점수가 잘 나와요.
