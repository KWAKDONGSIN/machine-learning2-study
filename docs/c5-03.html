계산 연습 — 정수로 끝나는 문제 ★

시험에서는 계산기를 못 써요. 하지만 시그모이드나 로그 같은 어려운 계산은 나오지 않고, "몇 나누기 몇", "몇 곱하기 몇" 수준의 정수 계산만 나온다고 교수님이 말했어요. 분수로 두고 약분하면 쉬워요.

연습 1. 200명 검사 결과가 TP=30, FP=10, FN=20, TN=140이에요.

지표계산값
정확도(30+140)/200 = 170/2000.85
정밀도30/(30+10) = 30/400.75
재현율30/(30+20) = 30/500.6
F12·0.75·0.6 / (0.75+0.6) = 0.9/1.35 = 2/3약 0.67

F1은 식 하나를 더 알면 빨라요. F1 = 2TP / (2TP + FP + FN)이에요. 여기에 넣으면 60/(60+10+20) = 60/90 = 2/3로 바로 나와요(이 식은 참고용이고, 시험에서는 위 정의대로 써도 돼요).

연습 2. 교수님 슬라이드의 검진 예시예요. 1,000명 중 환자 100명, TP=90, FN=10, FP=90, TN=810이에요.

  • 정확도 = (90+810)/1000 = 0.9
  • 정밀도 = 90/(90+90) = 90/180 = 0.5
  • 재현율 = 90/(90+10) = 90/100 = 0.9
  • F1 = 2·0.5·0.9 / (0.5+0.9) = 0.9/1.4 ≈ 0.64

정확도가 90%인데 정밀도는 겨우 0.5예요. 이 예시가 5-4의 핵심이에요.

연습 3 (문장으로 주어질 때). "실제 환자는 8명이다. 모델은 10명을 양성이라고 했고, 그중 6명이 진짜 환자였다. 정밀도와 재현율은?"

문장을 표로 바꾸는 게 첫 단계예요. "양성이라고 한 10명" = TP+FP이고 그중 진짜 6명 = TP이므로 FP=4예요. "실제 환자 8명" = TP+FN이므로 FN=2예요.

  • 정밀도 = 6/10 = 0.6
  • 재현율 = 6/8 = 0.75
시험엔 이렇게 써요

(계산형) 먼저 TP, FP, FN, TN을 문제에서 뽑아 적고, 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN)에 대입한다. 예) TP=6, FP=4, FN=2이면 정밀도 6/10 = 0.6, 재현율 6/8 = 0.75이다.

잠깐 확인 — TP=40, FP=10, FN=40, TN=110일 때 정밀도와 재현율은?

정밀도는 40/(40+10) = 40/50 = 0.8, 재현율은 40/(40+40) = 40/80 = 0.5예요. 정확도는 (40+110)/200 = 0.75이고요.
