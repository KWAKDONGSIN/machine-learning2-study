층 부품 알아보기 — Sequential · Input · Flatten · Dense · Dropout ★★

Sequential은 층을 "리스트에 적은 순서대로" 쌓는 모델이에요. 맨 위가 입력 쪽, 맨 아래가 출력 쪽이에요. MNIST MLP는 층 5개가 전부예요.

층 (코드)하는 일출력 모양파라미터
layers.Input(shape=(28,28))입력 모양을 선언해요. 28×28 흑백 이미지. 한 번에 몇 장 넣을지(배치)는 정하지 않아서 None이에요.(None, 28, 28)0
layers.Flatten()2차원 이미지를 1차원 784개짜리 한 줄로 펴요(28×28 = 784).(None, 784)0
layers.Dense(256, activation='relu')은닉층. 뉴런 256개가 각각 784개 입력을 가중합하고 ReLU를 통과시켜요.(None, 256)200,960
layers.Dropout(0.2)학습할 때 뉴런의 20%를 무작위로 꺼요(추론 때는 안 꺼요).(None, 256)0
layers.Dense(10, activation='softmax')출력층. 클래스 10개의 점수를 합이 1인 확률로 바꿔요.(None, 10)2,570
비유

Flatten은 격자무늬 종이를 풀어서 한 줄로 늘어놓는 일이에요. 숫자(픽셀) 28줄을 이어 붙여 784칸짜리 긴 줄을 만들어요. 그 긴 줄을 은닉층의 모든 뉴런이 한꺼번에 들여다봐요. 교수님은 "나중에 이게 되게 중요해진다"고 했는데, 펴는 순간 픽셀의 위아래 관계가 사라져서 이미지 전용 구조(CNN)가 필요해지기 때문이에요.

  • Dropout은 파라미터를 버리는 것이 아니에요. 학습 중에 뉴런을 껐다 켰다 하는 것이고, "파라미터에 0.2를 곱한다"는 오해를 하지 말라고 교수님이 짚었어요. 그래서 파라미터는 0개예요.
  • 마지막 Dense(10, …)의 10은 클래스 수(숫자 0~9)예요.
  • 마지막 층의 활성화·손실·라벨 형식은 세트예요(8-4).
시험엔 이렇게 써요

Flatten은 28×28 이미지를 784차원 벡터로 펴는 층으로 파라미터가 없다. Dense(256, activation='relu')는 완전 연결된 은닉층이고, Dropout(0.2)은 학습 때 뉴런의 20%를 무작위로 끄며, 마지막 Dense(10, activation='softmax')는 10개 클래스의 확률을 출력한다.

잠깐 확인 — Flatten 층의 파라미터 수와 출력 모양은? (입력이 28×28)

파라미터는 0개, 출력 모양은 (None, 784)예요. 모양만 바꾸고 계산하는 숫자는 없어요.
