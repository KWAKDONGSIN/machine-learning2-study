규제 — 릿지(L2)와 라쏘(L1) ★

과적합은 보통 가중치 w가 지나치게 커지면서 생겨요. 규제(regularization)는 "w가 커지면 벌점"을 손실에 더해 모델이 얌전해지게 하는 방법이에요.

새 손실 = 원래 손실 + λ × (w에 대한 벌점) λ(람다)가 클수록 벌점이 세서 모델이 단순해져요

벌점을 매기는 방식이 두 가지예요.

릿지 (Ridge) = L2라쏘 (Lasso) = L1
벌점w를 제곱해서 더한 값 (Σw²)w의 절댓값을 더한 값 (Σ|w|)
w의 변화모두 작아지지만 정확히 0은 거의 안 돼요일부가 정확히 0이 돼요
효과모든 특성을 조금씩 쓰며 안정적필요 없는 특성이 사라져서 변수 선택
잘 맞는 상황모든 특성이 조금씩 의미 있을 때특성이 아주 많고 중요한 것만 남기고 싶을 때
비유 — 짐 줄이기

릿지는 가방 속 모든 물건을 조금씩 덜어 내는 방식이고, 라쏘는 필요 없는 물건을 아예 가방에서 빼 버리는 방식이에요. 라쏘(Lasso)는 올가미라는 뜻이라서 안 쓰는 걸 잘라 내는 모습으로 떠올리면 쉬워요.

외우기 팁

Lasso는 L1 — 둘 다 L로 시작해요. 그러면 릿지는 자동으로 L2예요. 교수님도 이 둘을 바꿔 외우는 학생이 많다고 경고했어요.

정규화(normalization)와 규제(regularization)는 이름이 비슷하지만 달라요. 정규화·표준화는 입력 X의 크기를 맞추는 전처리이고, 규제는 모델의 w가 커지지 않게 하는 학습 장치예요.

시험엔 이렇게 써요

L2 규제(릿지)는 가중치 제곱합을 벌점으로 더해 가중치 크기를 줄이고, L1 규제(라쏘)는 가중치 절댓값 합을 벌점으로 더해 일부 가중치를 0으로 만들어 변수 선택 효과를 낸다. 규제 강도 λ가 클수록 모델이 단순해진다.

잠깐 확인 — 일부 계수를 정확히 0으로 만들어 변수를 골라 주는 규제는?

라쏘(L1)예요. 릿지(L2)는 계수를 작게는 만들지만 0으로 만들지는 않아요.

머신러닝2에서는 이렇게 이어져요

7장에서 L1 대 L2와 정규화 기법 표(Dropout, BatchNorm, 데이터 증강, 조기 종료, Label Smoothing)로 그대로 나와요. L2는 딥러닝에서 Weight Decay라고도 불러요.
