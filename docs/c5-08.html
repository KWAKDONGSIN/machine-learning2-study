이 장 3줄 요약
  • 혼동행렬은 행 = 실제, 열 = 예측이고, TP·TN은 맞힘, FP는 거짓 경보, FN은 놓침이에요(뒤 글자는 예측, 앞 글자는 맞았는지).
  • 정밀도 = TP/(TP+FP)로 분모는 예측 양성(열), 재현율 = TP/(TP+FN)으로 분모는 실제 양성(행)이고, 정확도는 대각선 합 / 전체, F1은 둘의 조화평균이에요.
  • 불균형 데이터에서는 "모두 음성" 모델도 정확도가 높으니 혼동행렬과 P/R을 함께 보고, 암 검진은 재현율, 스팸은 정밀도, 부정 거래는 F1과 임계값으로 비용에 맞춰 골라요.
