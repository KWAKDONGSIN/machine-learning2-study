시험지엔 이렇게 써요

버그가 아닌 정상 현상이다. Dropout(0.2)은 학습(fit) 중에는 매 스텝 뉴런의 20%를 무작위로 꺼서 일부만 쓰는 '약한 모델'로 학습 정확도를 측정한다. 반면 검증(evaluate·predict)에서는 Dropout이 꺼지고 모든 뉴런을 사용하므로 더 강한 모델로 측정된다. 따라서 초기 epoch에서는 학습 정확도 < 검증 정확도가 나올 수 있다.

정상 현상학습 때는 Dropout이 뉴런을 끔검증·추론 때는 전부 켬학습 정확도 < 검증 정확도

쉽게 말하면

직선을 아무리 이어 붙여도 결국 직선 하나예요. 중간에 '꺾는 장치'(활성화 함수)를 넣어야 구부러진 모양도 만들 수 있어요. Sigmoid는 기울기가 작아서 여러 층을 거치면 신호가 사라지는데, ReLU는 양수에서 기울기가 1이라 신호가 잘 전달돼요.

시험지엔 이렇게 써요

활성화 함수가 없으면 Dense 층은 가중합만 하므로 W₂(W₁x+b₁)+b₂ = W′x+b′처럼 선형∘선형=선형이 되어, 층을 100개 쌓아도 선형 분류기 하나와 같다. 비선형 활성화를 끼워야 층을 쌓는 의미가 생기고 직선으로 못 가르는 문제를 풀 수 있다. Sigmoid는 σ′ ≤ 0.25이고 양끝이 포화되어, 층마다 기울기가 곱해지면 앞쪽 기울기가 거의 0이 되는 기울기 소실이 생긴다. ReLU(max(0, x))는 양수 구간의 기울기가 1이라 곱해도 줄지 않아 기울기 소실이 적고 계산도 간단하다. 다만 음수 구간 기울기가 0이라 죽은 ReLU가 생길 수 있어 Leaky ReLU 등으로 완화한다.

쉽게 말하면

모델이 문제집을 통째로 외우지 못하게 방해하는 여러 방법이에요. 벌점을 주기(L1·L2), 일부 뉴런을 쉬게 하기(Dropout), 값을 반듯하게 정리하기(BatchNorm), 문제를 변형해서 늘리기(증강), 제일 좋을 때 멈추기(조기 종료)예요.

시험지엔 이렇게 써요

L1은 손실에 λΣ|w|를 더해 일부 가중치를 0으로 만들어(희소) 변수 선택 효과를 내고, L2는 λΣw²를 더해 가중치가 커지지 않게 제한한다(Weight Decay). Dropout은 학습 중 뉴런을 확률적으로 꺼서 특정 뉴런에 의존하지 못하게 하며 앙상블 효과를 낸다(추론 때는 전부 사용). BatchNorm은 각 층의 입력을 평균 0, 분산 1로 정규화해 학습을 안정시키고 약한 정규화 효과를 낸다. 데이터 증강은 회전·자르기 등으로 학습 데이터를 인위적으로 늘려 다양한 상황을 학습시킨다. 조기 종료는 검증 손실이 최소인 지점에서 학습을 멈춘다. 모두 모델이 학습 데이터를 외우는 것을 막아 새 데이터에서의 성능(일반화)을 높인다.
