연습 문제 — 직접 세어 보세요

종이에 식을 쓰고 풀어 본 뒤 답을 열어 보세요. 수십 번 보는 것보다 한 번 써 보는 것이 훨씬 오래가요.

연습 1 — 입력 10 → 은닉 20 → 출력 5

(10×20 + 20) + (20×5 + 5) = 220 + 105 = 325개예요.

연습 2 — 아이리스 분류기(특성 4개, 품종 3개)가 은닉층 없이 입력에서 바로 출력(softmax)으로 가면?

4×3 + 3 = 15개예요. 강의자료의 Softmax 회귀 모델이고, W는 4×3, b는 3개예요.

연습 3 — 784 → 256 → 128 → 10

(784×256 + 256) + (256×128 + 128) + (128×10 + 10) = 200,960 + 32,896 + 1,290 = 235,146개예요.

연습 4 — 784 → 64 → 10에서 W⁽¹⁾의 크기와 전체 파라미터 수는?

W⁽¹⁾는 (64, 784)이고, 전체는 (784×64 + 64) + (64×10 + 10) = 50,240 + 650 = 50,890개예요.

연습 5 — 파라미터가 많을수록 항상 좋은가요?

아니에요. 파라미터가 데이터에 비해 너무 많으면 과적합이 생기기 쉽고, 계산량도 늘어요. 효과가 점점 줄어드는 수확체감도 있어요.

시험엔 이렇게 써요

층 구성이 주어지면 층 사이마다 (앞 층 뉴런 수 × 이번 층 뉴런 수) + 이번 층 뉴런 수를 계산해 모두 더한다. 예를 들어 입력 3, 은닉 4, 출력 2이면 (3×4 + 4) + (4×2 + 2) = 26개이다.
