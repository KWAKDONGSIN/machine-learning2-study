가중합 z = wᵀx + b — 선형회귀와 같은 뿌리

한 줄 정의

가중합(weighted sum)은 입력마다 가중치를 곱해서 모두 더하고 편향을 더한 값이에요. 식은 z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = wᵀx + b예요.

1학기의 선형회귀는 y = w·x + b였어요. 입력이 여러 개가 되면 wᵀx + b가 되고, 신경망에서는 이것을 가중합이라고 불러요. 계산 방법은 완전히 같아요.

w(가중치)는 그 입력이 얼마나 중요한지를 나타내요. 교수님이 특히 강조한 점은 w가 사람이 정해 주는 값이 아니라는 거예요. 손실이 크면 계속 고치면서 모델이 학습으로 찾아내는 파라미터예요.

비유 — 성적 환산

"중간 20%, 기말 30%, 프로젝트 25%…" 하고 각 점수에 비율을 곱해 더하는 성적 환산이 가중합이에요. 신경망은 이 비율(가중치)을 사람이 아니라 데이터로 찾아요.

시험엔 이렇게 써요

뉴런 하나의 가중합은 z = wᵀx + b이며, 입력 각각에 가중치를 곱해 더하고 편향을 더한 값이다. 이 계산은 선형회귀와 같고, 가중치 w와 편향 b는 사람이 정하지 않고 학습으로 최적화되는 파라미터이다.

잠깐 확인 — 가중치 w는 누가 정하나요?

사람이 정하지 않아요. 손실을 줄이는 방향으로 모델이 학습하면서 계속 고쳐 가는 값이에요.
