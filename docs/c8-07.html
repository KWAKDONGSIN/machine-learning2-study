이 장 3줄 요약
  • Dense = 가중합 + 활성화 한 층, compile(optimizer · loss · metrics)이 갱신 방식·손실·지표, fit이 학습 루프와 자동 역전파, evaluate는 (loss, acc), predict는 확률 벡터예요.
  • MNIST MLP는 Sequential([Input, Flatten, Dense(…,'relu'), Dropout, Dense(10,'softmax')])이고, 손실은 정수 라벨 'sparse_categorical_crossentropy', 원-핫 'categorical_crossentropy', 이진·멀티라벨 'binary_crossentropy'예요.
  • 파라미터 = Dense마다 입력 × 출력 + 출력(Flatten·Dropout은 0)이라 784→256→10은 203,530개이고, 512로 바꾸면 407,050개예요.
