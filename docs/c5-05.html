3×3 혼동행렬 — 클래스 하나씩 "양성 대 나머지" ★

클래스가 셋 이상이면 표도 3×3으로 커져요. 방법은 간단해요. 지표를 알고 싶은 클래스 하나를 양성으로, 나머지를 전부 합쳐 음성으로 보면 2×2 표가 클래스마다 하나씩 나와요. 이것을 "양성 대 나머지"라고 불러요.

핵심은 행과 열을 구분하는 거예요.

알고 싶은 것어디를 보나계산
TP그 클래스의 대각선 칸(클래스 X, 클래스 X) 칸
FN (놓침)그 클래스의 행에서 대각선을 뺀 나머지실제 X인데 다른 것으로 예측
FP (거짓 경보)그 클래스의 열에서 대각선을 뺀 나머지실제는 다른 것인데 X로 예측
정밀도열 합이 분모TP ÷ 그 열의 합
재현율행 합이 분모TP ÷ 그 행의 합

행(실제)에서 가로로 읽으면 "이 클래스가 어디로 새는가"가 보이고, 열(예측)에서 세로로 읽으면 "이 예측에 무엇이 섞였는가"가 보여요.

예제 A — 교수님 슬라이드의 붓꽃 분류. 테스트 38개의 결과예요(행 = 실제, 열 = 예측).

실제 \ 예측setosaversicolorvirginica행 합
setosa111012
versicolor09413
virginica021113
열 합11121538
  • 정확도 = 대각선 합 / 전체 = (11+9+11)/38 = 31/38 ≈ 0.816
  • versicolor 정밀도 = 9 / (열 합 12) = 0.75 (FP = 열의 나머지 1+2 = 3)
  • versicolor 재현율 = 9 / (행 합 13) ≈ 0.69 (FN = 행의 나머지 0+4 = 4)
  • virginica는 재현율 11/13 ≈ 0.85인데 정밀도는 11/15 ≈ 0.73이에요. versicolor를 virginica로 4개나 잘못 부른 탓이에요.

예제 B — 고양이·개·토끼 (직접 풀어 봐요).

실제 \ 예측고양이개토끼
고양이5055
개103010
토끼5520

"개의 정밀도와 재현율은?"이라는 문제라면, 개 열은 5+30+5 = 40이고 개 행은 10+30+10 = 50이에요. 정밀도는 30/40 = 0.75, 재현율은 30/50 = 0.6이에요.

잠깐 확인 — 위 표에서 토끼의 정밀도와 전체 정확도는?

토끼 열의 합은 5+10+20 = 35이므로 정밀도는 20/35 = 4/7 ≈ 0.57이에요. 전체 정확도는 대각선 합 (50+30+20) = 100을 전체 140으로 나눈 100/140 ≈ 0.71이에요.

예제 C — 슬라이드의 7개 샘플 코드. 실제 [0,1,2,2,0,1,2], 예측 [0,0,2,1,0,2,2], 클래스 이름 A, B, C예요. 짝을 지어 세면 이런 표가 나와요.

실제 \ 예측ABC
A200
B101
C012
  • 정확도 = (2+0+2)/7 = 4/7 ≈ 0.571
  • B의 재현율 = 0/(1+0+1) = 0 (B 두 개를 모두 못 맞힘)
  • C의 정밀도 = 2/(0+1+2) = 2/3 (C라고 한 3개 중 B가 하나 섞임)

파이썬의 classification_report는 이 계산을 클래스마다 해서 정밀도·재현율·F1·support(그 클래스의 실제 개수 = 행 합)를 한 표로 보여 줘요.

외우기 팁

3×3 문제는 세 단계로 풀어요. ① 구하려는 클래스의 대각선 칸을 TP로 잡는다. ② 정밀도면 세로(열) 합, 재현율이면 가로(행) 합을 구한다. ③ TP를 그 합으로 나눈다. 행과 열을 헷갈릴 때는 "행 = 실제, 열 = 예측"을 먼저 써 두고 시작해요.

시험엔 이렇게 써요

다중 클래스에서는 클래스마다 해당 클래스를 양성, 나머지를 음성으로 놓고 지표를 계산한다. 특정 클래스의 정밀도는 대각선 값을 그 열(예측)의 합으로, 재현율은 대각선 값을 그 행(실제)의 합으로 나눈다. 정확도는 대각선 합을 전체 개수로 나눈다.
