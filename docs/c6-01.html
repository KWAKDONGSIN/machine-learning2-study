왜 필요한가 — 선형 ∘ 선형 = 선형 ★

뉴런 하나는 먼저 가중합 z = w·x + b를 계산해요. 이것은 x에 숫자를 곱하고 더하는 1차식, 즉 선형(직선)이에요. 그 뒤에 활성화 함수를 붙여서 값을 한 번 비틀어 줘요.

그런데 활성화 함수 없이 가중합만 두 층 쌓으면 어떻게 될까요? 숫자로 확인해 봐요. 첫 층이 z₁ = 2x + 1이고, 둘째 층이 z₂ = 3·z₁ + 2예요.

둘째 층에 첫 층을 넣으면 3·(2x+1)+2 = 6x + 3 + 2 = 6x + 5가 돼요. 이것도 그냥 직선 하나예요. 층이 2개가 아니라 100개여도 결과는 같아요.

행렬로 쓰면 식이 이렇게 돼요. a = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W′x + b′ 이고, W′와 b′는 그냥 새로운 숫자일 뿐이에요.

한 줄 정의

선형 ∘ 선형 = 선형. 활성화 함수가 없는 Dense를 여러 층 쌓아도 결국 "선형 분류기 하나"와 같아요.

비유 — 확대 복사기

2배 확대 복사기에 3배 확대 복사기를 이어 붙여도 결국 6배 복사기 한 대일 뿐이에요. 층을 쌓는 의미가 없어요. 중간에 "구부리거나 꺾는" 장치를 끼워야 복사기를 이어 붙인 효과가 생겨요. 그 장치가 활성화 함수예요.

왜 직선 하나가 문제일까요? 세상의 문제는 직선 하나로 가를 수 없는 경우가 많아요(대표적인 예가 XOR이고, 이 예는 시험 범위가 아니에요). 비선형 함수를 층 사이에 끼우면 그때마다 공간이 구부러져서, 층을 쌓을수록 더 복잡한 모양을 만들 수 있어요.

또 하나, 활성화 함수는 학습 때 기울기가 흐르는 방식을 정해요. 그래서 학습의 안정성과 속도도 활성화 함수에 크게 좌우돼요(6-3에서 봐요).

시험엔 이렇게 써요

활성화 함수가 없으면 선형 함수를 여러 번 합성해도 결과가 하나의 선형 함수 W′x+b′가 되므로, 은닉층을 쌓는 의미가 사라지고 모델이 선형 분류기 하나와 같아진다. 따라서 은닉층에는 비선형 활성화 함수가 필요하다.

잠깐 확인 — 활성화 함수 없이 Dense 3층을 쌓으면 어떤 모델이 되나요?

선형 모델 하나(W′x + b′)와 같아져요. 층을 쌓은 보람이 없어요.
