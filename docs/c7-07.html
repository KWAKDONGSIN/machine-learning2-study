모의 문제 — 곡선 읽고 쓰기

주관식 모의 1. 아래는 10 epoch 동안의 손실 기록이에요. 현상 이름, 근거, 멈춰야 할 epoch, EarlyStopping 설정, 완화 방법을 쓰세요.

epoch12345678910
학습 손실0.500.300.200.140.100.070.050.040.030.02
검증 손실0.550.380.300.270.260.270.290.320.360.40
모범 답안 보기

(현상) 과적합이에요. (근거) 학습 손실은 0.50에서 0.02까지 계속 줄지만 검증 손실은 epoch 5에서 최소(0.26)가 된 뒤 0.40까지 다시 올라 두 곡선의 간격이 벌어져요. (멈출 곳) 검증 손실이 최소인 epoch 5예요. (설정) EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True)이면 개선 없이 3 epoch이 지난 epoch 8에서 멈추고 epoch 5의 가중치를 복원해요. (완화) Dropout 비율을 올리고, L2를 걸고, 데이터 증강을 하거나 은닉 유닛 수를 줄여요.

주관식 모의 2. 학습·검증 손실이 모두 1.8 근처에서 거의 내려가지 않고, 두 선의 차이도 거의 없어요. 현상과 처방은?

모범 답안 보기

과소적합이에요. 둘 다 높은 손실에서 정체되고 간격이 좁아 모델이 학습 자체를 못 하고 있어요. 은닉 유닛과 층을 늘리고, 학습률이 너무 작으면 올리고, epoch을 늘리며, 입력이 0~1 등으로 정규화되었는지 확인해요.

주관식 모의 3. 학습·검증 손실이 모두 위아래로 크게 요동치며 내려가지 않아요. 현상과 처방은?

모범 답안 보기

학습률 과대예요. 한 번에 너무 크게 움직여서 손실 바닥을 계속 넘나들기 때문에 두 곡선이 모두 요동해요. 학습률을 10배쯤 낮춰요.

객관식 모의 1. 과적합을 완화하는 방법으로 알맞지 않은 것은?

  • ① Dropout 비율을 높인다
  • ② 은닉 유닛 수를 크게 늘린다
  • ③ 데이터 증강을 적용한다
  • ④ 검증 손실이 최소인 epoch에서 조기 종료한다
정답 보기

②예요. 모델을 키우면 파라미터가 더 많아져 과적합이 심해져요. 모델을 키우는 것은 과소적합의 처방이에요.

객관식 모의 2. 손실에 가중치 제곱의 합을 더해 가중치가 커지는 것을 제한하는 정규화는?

  • ① L1
  • ② L2 (Weight Decay)
  • ③ Dropout
  • ④ 데이터 증강
정답 보기

②예요. 제곱의 합은 L2, 절댓값의 합은 L1이에요. Dropout과 데이터 증강은 손실 식을 바꾸지 않아요.

객관식 모의 3. 배치 정규화(BatchNorm)에 대한 설명으로 옳은 것은?

  • ① 학습 때만 뉴런의 일부를 0으로 만든다
  • ② 각 층의 입력을 평균 0, 분산 1로 맞춘다
  • ③ 정답 라벨을 [0.9, 0.05, 0.05]처럼 퍼뜨린다
  • ④ 검증 손실이 안 줄면 학습을 멈춘다
정답 보기

②예요. ①은 Dropout, ③은 Label Smoothing, ④는 조기 종료예요.
