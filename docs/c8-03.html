MNIST 코드 한 줄씩 읽기 ★★★

교수님이 "Ctrl+Enter만 누르지 말고 코드 안을 읽으라"고 한 부분이에요. 데이터 불러오기는 중요도가 낮고, 모델을 만드는 부분(Sequential ~ compile)에서 반드시 시험을 낸다고 했어요. 순서대로 읽어요.

(1) 데이터 준비

(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data() x_train = (x_train / 255.0).astype("float32") x_test = (x_test / 255.0).astype("float32") x_val, y_val = x_train[:5000], y_train[:5000] x_trn, y_trn = x_train[5000:], y_train[5000:]
코드 줄무슨 뜻
tf.keras.datasets.mnist.load_data()MNIST 손글씨를 (학습 세트, 테스트 세트) 두 묶음으로 불러와요. 학습 60,000장, 테스트 10,000장, 28×28 흑백, 라벨은 정수 0~9.
x_train / 255.0픽셀 값 0~255를 0~1로 맞춰요(정규화). 입력 크기가 일정하면 학습이 안정되고 빨라져요.
.astype("float32")Keras의 기본 숫자 형식(32비트 소수)으로 바꿔요.
x_train[:5000]앞 5,000장을 검증용으로 떼요. 나머지 55,000장이 학습용이에요.

세트는 세 개예요. 학습 55,000장(가중치 갱신), 검증 5,000장(epoch마다 보며 하이퍼파라미터·조기 종료 판단), 테스트 10,000장(마지막에 한 번 최종 보고). 검증과 테스트를 헷갈리면 "다 틀린다"고 교수님이 강조했어요.

(2) 모델 만들기와 compile — 시험 출제 핵심

from tensorflow.keras import layers, models def build_mlp(hidden_units=256, dropout_rate=0.2): model = models.Sequential([ layers.Input(shape=(28,28)), layers.Flatten(), layers.Dense(hidden_units, activation='relu'), layers.Dropout(dropout_rate), layers.Dense(10, activation='softmax') ]) model.compile( optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='sparse_categorical_crossentropy', metrics=['accuracy'] ) return model model = build_mlp(hidden_units=256, dropout_rate=0.2) model.summary()
코드 줄무슨 뜻
def build_mlp(hidden_units=256, dropout_rate=0.2):모델을 만들어 돌려주는 함수. 은닉 뉴런 수와 Dropout 비율을 바꿔 가며 실험하려고 함수로 묶었어요(기본값 256, 0.2).
models.Sequential([ ... ])층을 위에서 아래로 순서대로 쌓은 모델.
layers.Input(shape=(28,28))입력은 28×28 배열.
layers.Flatten()28×28을 784로 펴기.
layers.Dense(hidden_units, activation='relu')은닉층 256개 뉴런, 활성화 ReLU.
layers.Dropout(dropout_rate)학습 때 20% 뉴런 끄기.
layers.Dense(10, activation='softmax')출력층, 10개 클래스 확률(합 = 1).
model.compile(...)학습 방법을 정해요. 인자는 세 가지(optimizer · loss · metrics)예요.
optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3)어떻게 갱신할지. Adam 옵티마이저, 학습률 0.001(= 1e-3, Adam의 기본값).
loss='sparse_categorical_crossentropy'무엇을 줄일지. 정수 라벨 + 다중 클래스용 교차 엔트로피.
metrics=['accuracy']무엇을 볼지. 정확도(손실 외에 같이 출력할 지표).
model.summary()층별 출력 모양과 파라미터 수를 표로 보여 줘요.

model.summary()의 실행 결과는 이렇게 나와요(화면 모양은 버전에 따라 조금 달라도 숫자는 같아요).

Layer (type) Output Shape Param # flatten (Flatten) (None, 784) 0 dense (Dense) (None, 256) 200,960 dropout (Dropout) (None, 256) 0 dense_1 (Dense) (None, 10) 2,570 Total params: 203,530 (795.04 KB) Trainable params: 203,530 Non-trainable params: 0

(3) 콜백, 학습, 평가, 예측

early_stop = tf.keras.callbacks.EarlyStopping( monitor='val_accuracy', patience=3, restore_best_weights=True ) history = model.fit( x_trn, y_trn, validation_data=(x_val, y_val), epochs=20, batch_size=128, callbacks=[early_stop], verbose=1 ) test_loss, test_acc = model.evaluate(x_test, y_test, verbose=0) print(f"[Test] loss={test_loss:.4f}, acc={test_acc:.4f}") y_pred_prob = model.predict(x_test, verbose=0) y_pred = np.argmax(y_pred_prob, axis=1)
코드 줄무슨 뜻
EarlyStopping(monitor='val_accuracy', patience=3, restore_best_weights=True)검증 정확도를 보다가, 개선 없이 3 epoch이 지나면 멈추고 가장 좋았던 때의 가중치로 되돌려요(자세한 동작은 9장).
model.fit(x_trn, y_trn, ...)학습 시작. 학습용 입력과 정답을 넣어요. 안에서 학습 루프와 역전파(자동 미분)가 돌아요.
validation_data=(x_val, y_val)epoch이 끝날 때마다 검증 세트로 val_loss, val_accuracy를 계산해요.
epochs=20, batch_size=128최대 20 epoch, 한 번에 128장씩 갱신.
callbacks=[early_stop]만든 콜백을 학습에 연결(리스트로 묶어요).
verbose=1진행 로그를 출력(0이면 조용히, 2면 epoch당 한 줄).
model.evaluate(x_test, y_test)테스트 세트로 평가. metrics=['accuracy']이므로 (손실, 정확도) 두 값을 돌려줘요.
model.predict(x_test)각 이미지의 클래스별 확률 벡터(10000, 10)를 돌려줘요.
np.argmax(y_pred_prob, axis=1)각 행(이미지)에서 확률이 가장 큰 칸의 번호 = 예측한 숫자.

실행 결과를 읽어 봐요. 로그에는 epoch마다 430/430(1 epoch의 step 수)과 학습·검증의 손실·정확도가 찍혀요. 마지막 평가는 [Test] loss=0.0643, acc=0.9811이에요. 즉 테스트 10,000장 중 189장을 틀렸어요(정확도 98.11%).

외우기 팁

시험에서 "이 코드의 결과는?"을 묻는 객관식은 손으로 따라가요. ① 층을 위에서부터 보며 출력 모양을 적고 ② Dense는 입력 × 출력 + 출력, Flatten·Dropout은 0으로 파라미터를 더하고 ③ 출력층의 뉴런 수는 클래스 수와 같다는 순서로요.

시험엔 이렇게 써요

compile은 optimizer(어떻게 갱신할지), loss(무엇을 줄일지), metrics(무엇을 볼지)를 지정한다. fit은 학습 루프와 역전파(자동 미분)를 수행하며 validation_data를 주면 epoch마다 val_loss와 val_accuracy를 계산한다. evaluate는 (손실, 정확도), predict는 확률 벡터를 반환하고 np.argmax(axis=1)로 클래스 번호를 얻는다.

잠깐 확인 — compile의 세 가지 인자 이름과 각각의 역할은?

optimizer는 가중치를 어떻게 갱신할지, loss는 무엇을 줄일지(손실 함수), metrics는 무엇을 함께 볼지(예 accuracy)를 정해요.
