코드 빈칸 연습 — 정답 철자를 손에 익혀요 ★★★

단답형은 이런 식으로 나와요. 정답은 대소문자, 따옴표, 언더바까지 똑같아야 해요. 먼저 철자 주의표를 눈에 익히고, 가린 답을 보지 않고 직접 써 봐요.

자주 틀리는 철자주의점
Sequential · Flatten · Dense · Dropout · Input층과 모델 이름은 첫 글자 대문자
EarlyStopping · Adam대문자 E, S와 A (Earlystopping 아님)
'relu' · 'softmax' · 'sigmoid'활성화 문자열은 전부 소문자이고 따옴표 안에 써요
'sparse_categorical_crossentropy'소문자, 단어 사이 언더바. entropy 앞이 cross 한 단어(crossentropy)
restore_best_weights · validation_data · batch_size언더바가 들어간 소문자. weights의 s, validation의 철자 주의
'val_accuracy' · 'val_loss' · 'accuracy'acc가 아니라 accuracy 전체

빈칸 1 — 모델 틀

model = models.__________([ layers.Input(shape=(28,28)), layers.__________(), layers.Dense(256, activation='__________'), layers.__________(0.2), layers.Dense(10, activation='__________') ])
정답 보기

순서대로 Sequential, Flatten, relu, Dropout, softmax예요.

빈칸 2 — compile

model.__________( optimizer=tf.keras.optimizers.__________(learning_rate=1e-3), loss='__________', metrics=['__________'] )
정답 보기

순서대로 compile, Adam, sparse_categorical_crossentropy(라벨이 정수일 때), accuracy예요.

빈칸 3 — 콜백과 fit 연결

early_stop = tf.keras.callbacks.__________( monitor='val_accuracy', __________=3, __________=True ) history = model.__________( x_trn, y_trn, __________=(x_val, y_val), epochs=20, __________=128, __________=[early_stop] )
정답 보기

순서대로 EarlyStopping, patience, restore_best_weights, fit, validation_data, batch_size, callbacks예요. 마지막 인자는 리스트 [early_stop]로 묶어요.

빈칸 4 — 평가와 예측

test_loss, test_acc = model.__________(x_test, y_test, verbose=0) y_pred_prob = model.__________(x_test, verbose=0) y_pred = np.__________(y_pred_prob, axis=1)
정답 보기

순서대로 evaluate, predict, argmax예요. evaluate는 (손실, 정확도), predict는 확률 벡터, argmax는 확률이 가장 큰 칸의 번호예요.

빈칸 5 — 라벨 형식에 맞는 손실 문자열

# (가) y_train이 정수 0~9, 모양 (55000,) model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='__________', metrics=['accuracy']) # (나) y_train이 원-핫, 모양 (55000, 10) model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='__________', metrics=['accuracy']) # (다) 스팸(1) / 정상(0) 이진 분류, 출력층이 Dense(1, activation='__________') model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='__________', metrics=['accuracy'])
정답 보기

(가) sparse_categorical_crossentropy, (나) categorical_crossentropy, (다) 출력층은 sigmoid, 손실은 binary_crossentropy예요.

정답 보기

순서대로 optimizer, loss, fit, metrics예요.

빈칸 7 — 학습 곡선 그리기

plt.plot(history.__________['accuracy']) plt.plot(history.history['__________']) plt.plot(history.history['__________']) plt.plot(history.history['__________'])

(아래 세 줄은 순서대로 검증 정확도, 학습 손실, 검증 손실이에요.)

정답 보기

첫 줄은 history.history['accuracy']의 history이고, 이어서 val_accuracy, loss, val_loss예요. history.history에는 epoch별 값이 리스트로 네 개(accuracy, val_accuracy, loss, val_loss) 쌓여 있어요.

빈칸 8 — 결과 분석 도구

from sklearn.metrics import __________, __________ cm = confusion_matrix(y_test, y_pred) print(__________(y_test, y_pred, digits=4))
정답 보기

confusion_matrix, classification_report, 그리고 마지막 줄도 classification_report예요. 혼동행렬(5장)과 클래스별 정밀도·재현율·F1·support 표를 만들어 줘요.

빈칸 9 — 이진 분류로 출력만 바꾸기

model = models.Sequential([ layers.Input(shape=(20000,)), layers.Dense(256, activation='relu'), layers.Dropout(0.5), layers.Dense(__, activation='__________') ]) model.compile( optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='__________', metrics=['accuracy'] )
정답 보기

출력 뉴런은 1개, 활성화는 sigmoid, 손실은 binary_crossentropy예요. 은닉 부분은 그대로이고 출력층과 손실만 문제 유형에 맞게 바뀌어요.

외우기 팁

코드를 통째로 외우기 어렵다면 "무엇이 바뀌는 자리인가"만 외워요. 바뀌는 자리는 ① 은닉 유닛 수와 Dropout 비율 ② 출력층 Dense(클래스 수, 활성화) ③ loss= 문자열 ④ 콜백 인자 세 개예요. 교수님은 "A 이상을 받고 싶으면 이 코드를 싹 다 외우고, B 정도면 외우지 않아도 된다, 배점이 크지 않다"고 했어요.

시험엔 이렇게 써요

(빈칸 답안 쓰는 요령) 층은 Dense·Flatten·Dropout처럼 첫 글자 대문자, 활성화와 손실은 따옴표 안에 소문자와 언더바로 'relu', 'softmax', 'sparse_categorical_crossentropy', 콜백 인자는 monitor, patience, restore_best_weights를 쓴다.
