어떤 오류가 더 비싼가 — 지표와 임계값 고르기 ★

FN과 FP는 틀린 정도가 같아도 값(비용)이 달라요. 어느 쪽이 더 아픈지에 따라 우선해서 볼 지표가 달라져요. 교수님은 이것을 "되게 실무적인 포인트"라고 했어요.

상황더 아픈 오류우선 지표와 이유
암 검진FN (환자를 놓침)재현율(Recall) 우선. 놓치면 생명이 위험하고, 거짓 경보(FP)는 재검사로 감당할 수 있어요.
스팸 차단FP (정상 메일을 스팸으로 차단)정밀도(Precision) 우선. 중요한 메일을 못 보는 것이 스팸 하나 받는 것보다 아파요.
부정 거래둘 다 비쌈, 그런데 부정 거래가 0.1%로 아주 드묾F1 + 임계값 조정. 정확도는 무의미(모두 정상이라 해도 99.9%)해요.
비유 — 교수님의 주식 비유

모델이 "산다(Yes)"고 하면 우리는 돈을 넣어요. 틀리면(FP) 진짜 손실이 나요. 반대로 모델이 "안 산다(No)"고 했는데 사실 올랐다면(FN) 돈을 번 기회를 놓친 것이라 손실은 안 나고 기회비용만 생겨요. 그래서 "양성이라고 말하는 순간 자원을 쓰는" 문제에서는 정밀도를 중요하게 봐요.

임계값(threshold)은 모델이 낸 확률이 몇 이상이면 "양성"이라고 부를지 정하는 기준선이에요. 보통은 0.5이지만 비용에 맞춰 옮겨요.

  • 임계값을 낮추면 (예 0.5 → 0.3) 양성 판정이 늘어서 재현율은 오르고 정밀도는 내려가요. 암 검진처럼 놓치면 안 될 때 써요.
  • 임계값을 높이면 (예 0.5 → 0.9) 확실할 때만 양성이라고 해서 정밀도는 오르고 재현율은 내려가요. 스팸 차단처럼 거짓 경보가 아플 때 써요.
  • 확률이 애매할 때는 자동으로 결정하지 않고 사람이 검토하도록 보류하는 방법도 실무에서 써요.

왜 정확도가 아니라 비용으로 정할까요? 임계값을 옮기면 정확도는 거의 그대로여도 FN과 FP의 개수가 서로 바뀌기 때문이에요. 어느 쪽 개수가 줄어야 이득인지는 비용이 정해요.

주관식 대비 — "문제 상황 → 출력층·지표·임계값·전처리" 답 쓰는 틀

예) "환자 사진으로 암 여부를 판정하는 모델을 만든다. 환자는 전체의 2%다."

  • 출력층 — 결과가 암/정상 두 가지(이진)이므로 출력 뉴런 1개, 활성화 sigmoid, 손실 binary cross-entropy
  • 지표 — 불균형(2%)이라 정확도는 무의미하고, 놓침(FN)이 치명적이므로 재현율을 우선하며 혼동행렬과 정밀도를 함께 보고
  • 임계값 — 0.5보다 낮춰(예 0.3) 재현율을 높이고, 늘어난 거짓 경보는 재검사로 처리
  • 전처리 — 입력 값을 같은 크기로 맞추는 표준화(평균 0, 표준편차 1)나 0~1 정규화를 하되, 기준값은 학습 데이터로만 계산해서(테스트 정보가 새지 않게) 테스트에도 그대로 적용
시험엔 이렇게 써요

암 검진은 환자를 놓치는 FN의 비용이 크므로 재현율을 우선하고 임계값을 낮춘다. 스팸 차단은 정상 메일을 막는 FP의 비용이 크므로 정밀도를 우선한다. 부정 거래처럼 양성이 극히 드문 경우는 정확도가 무의미하므로 F1과 임계값 조정으로 평가한다. (이유) 두 오류의 비용이 다르면 정확도 하나로는 모델을 선택할 수 없기 때문이다.

잠깐 확인 — 임계값을 0.5에서 0.3으로 낮추면 정밀도와 재현율은 각각 어떻게 되나요?

양성이라고 부르는 경우가 늘어나서 재현율은 오르고 정밀도는 내려가는 것이 보통이에요. 놓침은 줄고 거짓 경보는 늘어요.
