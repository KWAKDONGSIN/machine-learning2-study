연습 문제 — 객관식으로 풀어 봐요

문제 1. 혼동행렬에서 FN의 설명으로 옳은 것은?

  • ① 실제 음성을 음성으로 맞게 예측
  • ② 실제 음성을 양성으로 잘못 예측
  • ③ 실제 양성을 음성으로 잘못 예측
  • ④ 실제 양성을 양성으로 맞게 예측
정답 보기

③이에요. ①은 TN, ②는 FP, ④는 TP예요.

문제 2. 정밀도(Precision)를 구하는 식으로 옳은 것은?

  • ① TP / (TP + FN)
  • ② TP / (TP + FP)
  • ③ (TP + TN) / 전체
  • ④ TN / (TN + FP)
정답 보기

②예요. ①은 재현율, ③은 정확도예요. ④는 이 수업에서 쓰지 않는 다른 지표예요.

문제 3. 양성이 1%인 데이터에서 모든 입력을 음성이라고 답하는 모델에 대한 설명으로 옳은 것은?

  • ① 정확도 0.99, 재현율 0
  • ② 정확도 0.01, 재현율 1
  • ③ 정확도 0.5, 재현율 0.5
  • ④ 정확도 0.99, 재현율 1
정답 보기

①이에요. 음성 99%를 모두 맞혀 정확도는 0.99이고, 양성은 하나도 못 찾아 재현율은 0이에요.

문제 4. 3×3 혼동행렬(행 = 실제, 열 = 예측)에서 클래스 B의 재현율 분모로 알맞은 것은?

  • ① B 열의 합
  • ② B 행의 합
  • ③ 대각선의 합
  • ④ 전체 합
정답 보기

②예요. 재현율의 분모는 "실제 B 전부"이고, 행이 실제이므로 B 행의 합이에요. 열의 합은 정밀도의 분모예요.

문제 5. 정상 메일이 스팸으로 분류되어 중요한 연락을 놓치는 것이 가장 큰 문제인 스팸 필터에서 우선해야 할 지표는?

  • ① 재현율
  • ② 정밀도
  • ③ 학습 손실
  • ④ epoch 수
정답 보기

②예요. 정상 메일을 스팸이라고 하는 것은 FP이고, FP를 줄이는 지표가 정밀도예요.
