코드로 읽기 — 한 스텝과 200번 반복

경사하강의 한 스텝을 코드로 보면 이래요. 3장에서 본 update_weights의 마지막 두 줄이 학습률이 쓰이는 곳이에요.

w_grad = loss_grad * x b_grad = loss_grad w -= learning_rate * w_grad # w ← w − η·기울기 b -= learning_rate * b_grad # b ← b − η·기울기
코드 줄무슨 뜻
w_grad = loss_grad * x가중치의 기울기. 입력 x가 클수록 그 가중치가 더 많이 움직여요
b_grad = loss_grad편향의 기울기
w -= learning_rate * w_grad기울기에 학습률을 곱해서 빼요. w ← w − η·∂L/∂w 그대로예요

x = [2, 3, 1], 정답 [1, 0, 0], w = [0.5, −0.2, 0.8], b = 1, learning_rate = 0.1로 한 번 갱신하고 직접 실행한 결과예요.

업데이트된 가중치: [ 0.5199501 -0.47007485 0.70997505] 업데이트된 편향: [1.00997505 0.90997505 0.90997505] 손실 기울기: [-0.09975049 0.90024951 0.90024951]

손으로 따라가면 a = sigmoid(2.2) ≈ 0.900이라서 loss_grad = a − y ≈ [−0.10, 0.90, 0.90]이고, w_grad = loss_grad × x = [−0.2, 2.7, 0.9]예요. 여기에 0.1을 곱해 빼면 w의 첫 칸은 0.5 − 0.1×(−0.2) = 0.52가 돼요. 강의자료 슬라이드에 적힌 결과 숫자는 이 코드의 실제 실행 결과와 달라 보여요(자료에도 "다르면 직접 실행해 확인"이라는 주석이 있어요). 이 코드는 뉴런 하나에 3-클래스 정답을 넣은 교육용 단순화라서, 숫자보다 "예측 − 정답 → 학습률 곱하기 → 빼기" 순서만 기억하세요.

한 스텝만으로는 변화가 작아요. 이것을 수백 번 반복하는 것이 학습이에요. 아이리스 분류기는 200번 반복해요.

lr = 0.1 epochs = 200 for ep in range(epochs): Z = X_tr @ W + b # 순전파: 가중합 P = softmax(Z) # 확률 loss = cross_entropy(Y_tr, P) # 손실 dZ = (P - Y_tr) / X_tr.shape[0] # 기울기 (예측 − 정답) dW = X_tr.T @ dZ db = np.sum(dZ, axis=0, keepdims=True) W -= lr * dW # 경사하강 업데이트 b -= lr * db

이 루프에서 학습률은 W -= lr * dW 줄에서 쓰여요. 같은 모델을 Keras로 쓰면 아래처럼 대응돼요. 강의 Chapter 3의 "NumPy 줄과 Keras 객체 짝짓기" 문제와 연결돼요.

NumPy (이 장)Keras
cross_entropy(Y, P)loss='categorical_crossentropy' (compile)
W -= lr * dW (경사하강 업데이트)optimizer=SGD(learning_rate=0.1) (compile)
dZ, dW, db (기울기 계산)자동 미분 (fit 안에서 자동으로 해 줘요)
for ep in range(200)fit(epochs=200)
시험엔 이렇게 써요

경사하강 코드에서 W -= lr * dW 줄이 w ← w − η·∂L/∂w에 해당한다. Keras에서는 compile의 optimizer가 이 갱신을 맡고, fit이 자동 미분과 반복(epochs)을 수행한다.

잠깐 확인 — 코드에서 학습률은 어느 줄에 곱해지나요?

W -= lr * dW 줄이에요. 기울기 dW에 학습률 lr을 곱한 만큼 W에서 빼요.
