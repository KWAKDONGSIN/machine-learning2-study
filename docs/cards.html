용어 · 이름 (39)

ANN
Artificial Neural Network (인공신경망)

뇌의 뉴런을 흉내 낸 학습 모델

MLP
Multi-Layer Perceptron (다층 퍼셉트론)

은닉층이 1개 이상인 신경망

DNN
Deep Neural Network (심층 신경망)

은닉층이 2개 이상인 신경망

ReLU
Rectified Linear Unit

max(0, x). 음수는 0, 양수는 그대로. 양수 기울기 1

Leaky ReLU
Leaky Rectified Linear Unit

음수에서도 작은 기울기(0.01x)를 남긴 ReLU. 죽은 ReLU 완화

Sigmoid (σ)
Sigmoid function (시그모이드)

어떤 값이든 (0, 1)로 눌러 주는 S자 함수. σ′ ≤ 0.25

Tanh
Hyperbolic Tangent (쌍곡탄젠트)

(−1, 1) 범위의 0 중심 S자 함수

Softmax
Soft maximum

점수(로짓)를 합이 1인 확률 분포로 바꾸는 함수

CE
Cross-Entropy (교차 엔트로피)

L = −log(정답 확률). 자신 있게 틀릴수록 벌점이 큼

BCE
Binary Cross-Entropy

이진·멀티라벨용 크로스 엔트로피 (binary_crossentropy)

MSE
Mean Squared Error (평균제곱오차)

오차를 제곱해 평균 낸 회귀용 손실

TP
True Positive

양성을 양성이라고 맞힘

TN
True Negative

음성을 음성이라고 맞힘

FP
False Positive

음성인데 양성이라고 잘못 예측 (거짓 경보)

FN
False Negative

양성인데 음성이라고 잘못 예측 (놓침)

Precision
정밀도

양성이라고 한 것 중 진짜 양성 비율 = TP / (TP + FP)

Recall
재현율

진짜 양성 중 찾아낸 비율 = TP / (TP + FN)

F1
F1 score

정밀도와 재현율의 조화평균 = 2PR / (P + R)

epoch
에포크

학습 데이터 전체를 한 바퀴 다 쓰는 것

batch
배치 (묶음)

한 번에 같이 보는 샘플 묶음 (batch_size)

step
스텝

배치 하나로 가중치를 1회 갱신하는 것. 1 epoch = ⌈샘플 수 / batch_size⌉ step

Dropout
드롭아웃

학습 때 뉴런을 확률적으로 끄는 정규화. 추론 때는 전부 사용

BN
Batch Normalization (배치 정규화)

층 입력을 평균 0, 분산 1로 맞춰 학습을 안정시킴

L1
Lasso (라쏘)

손실에 λΣ|w| 추가. 일부 가중치를 0으로 만들어 변수 선택

L2
Ridge (릿지)

손실에 λΣw² 추가. 가중치가 커지지 않게 제한

Weight Decay
가중치 감쇠

L2와 같은 일을 하는 옵티마이저 옵션 (AdamW 등)

EarlyStopping
조기 종료

검증 지표가 개선되지 않으면 학습을 멈추는 콜백

patience
인내심

개선 없이 기다려 줄 epoch 수. 3이면 연속 3번 무개선 시 정지

SGD
Stochastic Gradient Descent (확률적 경사하강)

미니배치 기울기 방향으로 한 걸음씩 가는 가장 기본 옵티마이저

RMSProp
Root Mean Square Propagation

기울기 크기의 지수이동평균으로 학습률을 조절

Adam
Adaptive Moment Estimation

Momentum + RMSProp + 편향 보정. 기본 학습률 1e-3

η (lr)
learning rate (학습률)

한 번에 얼마나 움직일지 정하는 보폭. 가장 중요한 하이퍼파라미터

logit
로짓

출력층의 가중합. 아직 확률이 아닌 실수 점수

one-hot
원-핫 인코딩

정답 칸만 1, 나머지는 0인 라벨. 예 [0, 1, 0]

Dense
완전연결층

가중합 → 활성화를 하는 한 층. 파라미터 = in × out + out

Flatten
평탄화

2D 이미지를 1D 벡터로 펴는 층 (28×28 → 784). 파라미터 0

compile
컴파일 (학습 설정)

optimizer(어떻게 갱신) · loss(무엇을 줄일지) · metrics(무엇을 볼지)를 정함

fit
학습 실행

학습 루프와 자동 미분(역전파)을 돌리는 Keras 함수

NaN
Not a Number

계산이 터져 숫자가 아니게 된 값. 학습률이 너무 클 때(발산)의 신호
