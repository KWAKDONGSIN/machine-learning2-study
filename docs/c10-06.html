로지스틱 회귀 — 시그모이드, 확률, 임계값 ★

이름은 회귀지만 사실은 분류 모델이에요. 선형회귀처럼 점수 z = wᵀx + b를 먼저 구하는데, 이 점수는 −100도 1000도 될 수 있어서 확률로 쓸 수 없어요. 그래서 시그모이드(sigmoid) 함수에 넣어 0과 1 사이로 눌러 줘요.

σ(z) = 1 / (1 + e⁻ᶻ) z가 아주 작으면 0 근처, z = 0이면 정확히 0.5, z가 아주 크면 1 근처

결과는 "이 샘플이 1번 클래스(예 스팸)일 확률"로 읽어요. 예를 들어 0.82면 82%예요. 확률을 최종 답(0 또는 1)으로 바꾸려면 기준선, 즉 임계값(threshold)이 필요해요. 보통 0.5를 써요.

확률 p임계값 0.5임계값 0.2
0.821 (양성)1 (양성)
0.300 (음성)1 (양성)
0.100 (음성)0 (음성)

임계값을 낮추면 양성이라고 답하는 경우가 늘어요. 그러면 놓치는 환자는 줄지만(재현율 상승) 헛경보는 늘어요(정밀도 하락). 이 맞바꿈은 다음 소단원에서 정확히 다뤄요.

비유 — 합격선

시그모이드는 점수를 0~100%로 바꾸는 환산표이고, 임계값은 합격선이에요. 합격선을 낮추면 합격자는 늘어나지만 부적격자도 섞여 들어와요.

손실은 MSE 대신 교차엔트로피(cross-entropy)를 써요. "정답에 얼마나 높은 확률을 줬나"를 채점하고, 자신 있게 틀리면 벌점이 크게 커져요. 클래스가 3개 이상이면 시그모이드 대신 소프트맥스(softmax)를 쓰고, 이것이 신경망 분류기의 마지막 층이에요.

시험엔 이렇게 써요

로지스틱 회귀는 선형 점수 z = wᵀx + b를 시그모이드에 통과시켜 0~1 사이의 확률로 바꾸는 분류 모델이다. 확률을 임계값(보통 0.5)과 비교해 클래스를 정하며, 임계값을 낮추면 양성 판정이 늘어 재현율은 오르고 정밀도는 내려간다.

잠깐 확인 — z = 0일 때 시그모이드 값은?

정확히 0.5예요. 반반이라는 뜻이고, 이 점이 결정경계가 돼요.

머신러닝2에서는 이렇게 이어져요

1장에서 뉴런 하나 = 가중합 + 시그모이드이면 곧 로지스틱 회귀예요. 3장에서 출력층 세트(이진은 Sigmoid + Binary CE, 다중은 Softmax + CE)와 임계값 활용을 배우고, 6장에서 시그모이드 그래프와 포화(기울기 소실)를 봐요.
