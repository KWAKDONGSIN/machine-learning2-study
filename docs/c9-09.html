이 장 3줄 요약
  • step은 배치 하나로 한 번 갱신, epoch은 학습 데이터 한 바퀴예요. 1 epoch의 step 수 = ⌈학습 샘플 수 / batch_size⌉이고 55,000 / 128이면 430, 로그의 430/430은 그 step 수예요(배치를 키우면 갱신 횟수가 줄어요).
  • EarlyStopping(monitor, patience, restore_best_weights, mode)은 최고 기록을 연속 patience epoch 못 넘으면 멈추고, 최고 epoch 가중치로 복원해요(멈춤 = 최고 epoch + patience). fit의 callbacks=[…]로 연결하고 validation_data가 있어야 val_*가 생겨요.
  • Dropout은 학습 때만 끄고 추론 때는 전부 켜서 첫 epoch에 학습 정확도 < 검증 정확도가 나오고, val_loss는 확률의 품질까지 봐서 과적합을 더 일찍 드러내요. 옵티마이저는 SGD → Momentum → RMSProp → Adam(기본 lr 1e-3)이에요.
