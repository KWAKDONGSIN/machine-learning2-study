머신러닝Machine Learning
컴퓨터에게 규칙을 일일이 가르치는 대신, 예시 데이터를 많이 보여 주고 스스로 규칙을 찾게 하는 방법이에요. 아이에게 고양이 사진을 많이 보여 주면 고양이를 알아보게 되는 것과 비슷해요.
딥러닝Deep Learning
뉴런을 여러 층으로 깊게 쌓은 신경망으로 하는 머신러닝이에요. 사진, 소리, 글처럼 사람이 규칙을 만들기 어려운 데이터에 강해요.
인공신경망Artificial Neural Network
사람 뇌의 뉴런이 연결된 모습을 흉내 낸 계산 모델이에요. 입력층, 은닉층, 출력층으로 이루어져 있어요.
지도학습Supervised Learning
문제와 정답이 같이 붙은 문제집으로 공부하는 방식이에요. 사진마다 숫자 라벨이 붙은 MNIST가 대표적이에요.
분류Classification
정해진 몇 개의 칸 중에서 하나를 고르는 문제예요. 스팸인지 아닌지, 숫자 0~9 중 무엇인지 맞히는 것이 분류예요.
회귀Regression
집값이나 기온처럼 이어지는 숫자를 맞히는 문제예요. 칸을 고르는 것이 아니라 숫자 하나를 내놓아요.
특성Feature
정답을 맞히는 데 쓰는 단서예요. 집값을 맞힌다면 방 개수, 넓이, 위치가 특성이에요.
라벨Label
각 데이터에 붙은 정답이에요. 손글씨 사진에 붙은 '7' 같은 이름표를 말해요.
학습 데이터Training set
모델이 공부하는 데 쓰는 데이터예요. 가중치를 고치는 데 쓰이는 연습 문제집이에요.
검증 데이터Validation set
공부하는 중간에 실력을 확인하는 모의고사예요. 하이퍼파라미터를 고르고 EarlyStopping이 멈출 때를 정하는 데 써요.
테스트 데이터Test set
모든 공부가 끝난 뒤 마지막에 딱 한 번 보는 진짜 시험이에요. 이걸 보고 다시 고치면 안 돼요.
정보 누수Data Leakage
시험 문제를 미리 보고 공부한 것처럼, 테스트 정보가 학습에 새어 들어가는 일이에요. 그러면 점수가 실제보다 좋게 나와서 속게 돼요.
0~1 정규화Normalization
숫자의 범위를 0~1 사이로 맞추는 거예요. 픽셀 값 0~255를 255로 나누면 학습이 안정되고 빨라져요.
표준화Standardization
평균을 0, 표준편차를 1로 맞추는 거예요. 단위가 다른 값들을 같은 눈금으로 비교하게 해 줘요. 학습 데이터로만 계산하고 테스트에는 그대로 적용만 해요.
하이퍼파라미터Hyperparameter
학습 전에 사람이 직접 정해 주는 값이에요. 학습률, batch_size, epoch 수가 대표적이에요. 모델이 스스로 찾는 값(파라미터)과 달라요.
파라미터Parameter
모델이 학습으로 스스로 찾아내는 값이에요. 가중치와 편향이 파라미터이고, model.summary()의 Total params가 이 개수예요.
시드Seed
컴퓨터의 무작위 숫자를 매번 똑같이 만들어 주는 출발 번호예요. 시드를 고정하면 실행할 때마다 같은 결과를 볼 수 있어요.
벡터Vector
숫자를 한 줄로 늘어놓은 것이에요. 28×28 이미지를 펴면 784개짜리 벡터가 돼요.
행렬Matrix
숫자를 가로세로 표 모양으로 배열한 것이에요. 가중치 W는 보통 행렬이에요.
내적Dot product
두 줄의 숫자를 짝지어 곱한 뒤 모두 더하는 계산이에요. 가중합이 바로 입력과 가중치의 내적이에요.
로그Logarithm
'몇 번 곱해야 이 수가 되나'를 알려 주는 계산이에요. 시험에서는 로그 값을 손으로 계산하지 않고, −log p 그래프의 모양만 읽으면 돼요.
미분Derivative
어떤 값이 조금 변할 때 결과가 얼마나 변하는지를 알려 주는 계산이에요. 산에서 '지금 서 있는 곳의 가파른 정도'라고 생각하면 돼요.
기울기Gradient
지금 위치에서 어느 쪽이 오르막이고 얼마나 가파른지를 알려 주는 값이에요. 손실을 줄이려면 기울기의 반대쪽으로 가요.
뉴런Neuron
신경망의 가장 작은 계산 단위예요. 입력을 받아 가중합을 구하고 활성화 함수를 통과시켜 하나의 값을 내보내요.
퍼셉트론Perceptron
다수의 값을 입력받아 하나의 값을 출력하는 인공신경망의 기본 단위예요. 신경망이라는 건물의 벽돌 한 장이에요.
가중치Weight
각 입력이 얼마나 중요한지를 나타내는 숫자예요. 학습은 이 숫자를 좋은 값으로 고쳐 가는 일이에요.
편향Bias
직선의 절편처럼 결정경계를 위아래로 옮겨 주는 숫자예요. 뉴런마다 하나씩 있고, 입력이 0이어도 출력을 조절할 수 있게 해 줘요.
가중합Weighted sum
입력에 가중치를 곱해서 모두 더하고 편향을 더한 값이에요. z = wᵀx + b로 써요.
활성화 함수Activation function
가중합을 받아 비선형으로 바꿔 주는 함수예요. 이게 없으면 층을 아무리 쌓아도 직선 하나와 같아요.
선형Linear
그래프가 곧은 직선인 관계예요. 선형을 아무리 겹쳐도 결국 선형이라서 비선형 활성화 함수가 필요해요.
비선형Nonlinear
그래프가 직선이 아니라 꺾이거나 휘어진 관계예요. 활성화 함수가 이 성질을 넣어 줘요.
선형회귀Linear Regression
y = wx + b 모양의 직선으로 숫자를 예측하는 1학기 방법이에요. 신경망 뉴런에서 활성화 함수만 뺀 것과 같아요.
로지스틱 회귀Logistic Regression
가중합에 시그모이드를 붙여 0~1 사이 확률을 내는 분류 방법이에요. 뉴런 하나와 같은 계산이에요.
결정경계Decision boundary
모델이 '이쪽은 A, 저쪽은 B'라고 가르는 경계선이에요. 편향은 이 선을 평행하게 옮겨 줘요.
임계값Threshold
확률이 이 값을 넘으면 '양성'이라고 판정하는 기준선이에요. 0.5가 기본이지만 틀렸을 때의 비용에 따라 바꿔요.
입력층Input layer
데이터가 처음 들어오는 층이에요. 학습할 가중치는 없고 입력 모양만 알려 줘요.
은닉층Hidden layer
입력층과 출력층 사이에서 특징을 뽑아내는 층이에요. 겉에서 안 보여서 '숨은' 층이라고 불러요.
출력층Output layer
최종 답을 내놓는 마지막 층이에요. 문제 유형에 따라 뉴런 수와 활성화 함수가 정해져요.
다층 퍼셉트론Multi-Layer Perceptron
퍼셉트론을 여러 층으로 쌓은 신경망이에요. 은닉층이 1개 이상이면 MLP예요.
심층 신경망Deep Neural Network
은닉층이 2개 이상인 신경망이에요. 층이 깊어질수록 더 복잡한 특징을 배울 수 있어요.
단층 퍼셉트론Single-layer perceptron
은닉층이 없는 가장 단순한 신경망이에요. 직선 하나로 가를 수 있는 문제만 풀 수 있어요.
순전파Forward propagation
입력이 가중합과 활성화를 거치며 앞에서 뒤로 흘러 최종 예측을 만드는 과정이에요.
유닛Unit
한 층에 들어 있는 뉴런을 부르는 말이에요. Dense(256)이면 유닛이 256개예요.
DenseDense layer
모든 입력이 모든 뉴런에 연결된 층이에요. '가중합 → 활성화' 한 번을 해요. 파라미터 수는 입력 × 출력 + 출력이에요.
FlattenFlatten
2차원 이미지를 한 줄로 펴 주는 층이에요. 28×28 이미지가 784개짜리 벡터가 돼요. 학습할 값이 없어서 파라미터가 0개예요.
InputInput
모델이 받을 입력의 모양을 알려 주는 선언이에요. Input(shape=(28,28))이면 28×28 이미지를 받는다는 뜻이에요.
Total paramsTotal parameters
model.summary()에서 맨 아래 보이는 전체 파라미터 수예요. 784→256→10이면 203,530개예요.
로짓Logit
출력층의 가중합이에요. 아직 확률이 아닌 그냥 점수라서 Softmax를 통과시켜야 확률이 돼요.
SoftmaxSoftmax
점수들을 합이 1인 확률로 바꿔 주는 함수예요. 가장 높은 점수가 가장 높은 확률이 되고 순위는 그대로예요.
확률 분포Probability distribution
여러 선택지가 될 확률을 모아 놓은 것으로, 모두 0~1이고 합이 1이에요. Softmax의 출력이 이 모양이에요.
원-핫 인코딩One-hot encoding
정답 칸만 1이고 나머지는 0인 라벨이에요. 클래스가 3개이고 정답이 두 번째면 [0, 1, 0]이에요.
손실 함수Loss function
모델의 예측이 정답과 얼마나 다른지를 숫자 하나로 채점하는 함수예요. 학습은 이 숫자를 줄이는 일이에요.
크로스 엔트로피Cross-Entropy
L = −log(정답 확률)로 확률을 채점해요. 정답을 높은 확률로 맞히면 벌점이 작고, 자신 있게 틀리면 벌점이 커요.
이진 분류Binary classification
둘 중 하나를 고르는 문제예요. 출력층은 Sigmoid 뉴런 1개, 손실은 binary crossentropy를 써요.
다중 클래스Multi-class
셋 이상 중 정답이 하나뿐인 문제예요. 출력층은 Softmax, 손실은 categorical crossentropy를 써요.
멀티라벨Multi-label
정답이 여러 개일 수 있는 문제예요. 영화에 액션과 코미디 태그가 동시에 붙는 것처럼요. 출력층은 Sigmoid를 클래스 수만큼 써요.
MSEMean Squared Error
오차를 제곱해서 평균 낸 값이에요. 집값 같은 회귀 문제의 손실로 써요.
sparse_categorical_crossentropySparse categorical crossentropy
라벨이 0~9 같은 정수 그대로일 때 쓰는 다중 클래스 손실이에요. 원-핫으로 바꾸지 않아도 돼서 간편해요.
categorical_crossentropyCategorical crossentropy
라벨이 원-핫일 때 쓰는 다중 클래스 손실이에요. sparse가 안 붙은 것이 원-핫용이에요.
binary_crossentropyBinary crossentropy
이진 분류나 멀티라벨에서 Sigmoid와 짝으로 쓰는 손실이에요.
과신Overconfidence
모델이 틀리는 데도 확률을 너무 높게 주는 것이에요. Softmax 0.9가 실제로 90% 맞는다는 보장은 없어요.
Top-kTop-k
확률이 높은 순으로 상위 k개 후보를 보여 주는 방식이에요. 1등만 필요한 게 아닐 때 써요.
보류Defer
확신이 낮으면 자동으로 판정하지 않고 사람에게 넘기는 방식이에요. 틀린 자동 결정보다 보류가 싼 의료·서류 분류에 좋아요.
경사하강법Gradient Descent
산을 내려가듯 기울기의 반대 방향으로 가중치를 조금씩 옮겨 손실을 줄이는 방법이에요. w ← w − η·∂L/∂w로 써요.
학습률Learning rate
한 번에 얼마나 움직일지 정하는 보폭이에요. 너무 작으면 느리고 너무 크면 발산해요. 가장 먼저 만지는 하이퍼파라미터예요.
발산Divergence
보폭이 너무 커서 손실이 줄지 않고 점점 커지는 것이에요. 심하면 NaN이 떠요.
NaNNot a Number
계산이 터져서 숫자가 아니게 된 값이에요. 학습 도중 loss가 NaN이면 학습률이 너무 큰 경우가 많아요.
손실 곡선Loss curve
epoch마다 손실이 어떻게 변하는지 그린 그래프예요. 모양을 보면 학습률이 맞는지, 과적합인지 진단할 수 있어요.
옵티마이저Optimizer
기울기를 받아 가중치를 어떻게 고칠지 정하는 방식이에요. SGD, Momentum, RMSProp, Adam이 있어요.
SGDStochastic Gradient Descent
미니배치로 구한 기울기 방향으로 한 걸음씩 가는 가장 기본적인 옵티마이저예요. 단순하지만 학습률에 민감해요.
MomentumMomentum
굴러가는 공처럼 이전에 움직이던 방향을 관성으로 누적하는 방식이에요. 진동을 줄이고 작은 턱을 넘게 도와요.
RMSPropRMSProp
기울기 크기의 최근 평균을 이용해 파라미터마다 학습률을 조절하는 방식이에요.
AdamAdam
Momentum과 RMSProp과 편향 보정을 합친 옵티마이저예요. 대부분 문제의 기본값이고 기본 학습률은 1e-3이에요.
미니배치Mini-batch
데이터를 한꺼번에 쓰지 않고 작은 묶음(배치)으로 나눠서 쓰는 거예요. 한 묶음마다 가중치를 한 번 고쳐요.
혼동행렬Confusion matrix
예측과 실제 정답을 표로 비교한 것이에요. 이 수업에서는 행이 실제, 열이 예측이고 대각선이 맞힌 칸이에요.
TPTrue Positive
실제도 양성, 예측도 양성인 경우예요. 환자를 환자라고 맞힌 것이에요.
TNTrue Negative
실제도 음성, 예측도 음성인 경우예요. 정상인을 정상이라고 맞힌 것이에요.
FPFalse Positive
실제는 음성인데 양성이라고 잘못 예측한 경우예요. 거짓 경보라고 생각하면 돼요.
FNFalse Negative
실제는 양성인데 음성이라고 놓친 경우예요. 환자를 정상이라고 한 셈이라 암 검진에서는 치명적이에요.
정확도Accuracy
전체 중에서 맞힌 비율이에요. (TP+TN)/전체로 계산해요. 클래스가 불균형하면 속기 쉬워요.
정밀도Precision
양성이라고 한 것 중에 진짜 양성인 비율이에요. TP/(TP+FP)로 계산해요. 거짓 경보가 아플 때 높여요.
재현율Recall
진짜 양성 중에 잘 찾아낸 비율이에요. TP/(TP+FN)으로 계산해요. 놓치면 안 되는 암 검진에서 중요해요.
F1F1 score
정밀도와 재현율의 조화평균이에요. 둘 중 한쪽만 좋으면 낮게 나와서 균형을 볼 때 써요.
조화평균Harmonic mean
작은 쪽에 끌려가는 평균이에요. 정밀도 0.5와 재현율 1.0의 단순 평균은 0.75지만 조화평균(F1)은 0.67이에요.
유병률Prevalence
전체 중에 병이 있는 사람의 비율이에요. 유병률이 10%면 열 명 중 한 명이 환자라는 뜻이에요.
클래스 불균형Class imbalance
어느 한 종류의 데이터가 압도적으로 많은 상황이에요. 다 정상이라고만 해도 정확도가 높게 나와서 정확도만 보면 속아요.
시그모이드Sigmoid
어떤 값이든 0~1 사이로 눌러 주는 S자 함수예요. 확률처럼 읽을 수 있어서 이진 분류 출력층에 써요. 도함수는 최대 0.25예요.
탄젠트Tanh
시그모이드와 비슷한 S자인데 범위가 −1~1이고 0을 중심으로 대칭이에요.
ReLUReLU
max(0, x)라서 음수는 0, 양수는 그대로 통과시켜요. 양수 구간 기울기가 1이라 은닉층의 기본으로 가장 많이 써요.
Leaky ReLULeaky ReLU
음수 구간에서도 아주 작은 기울기(0.01x)를 남긴 ReLU예요. 뉴런이 죽는 것을 막아 줘요.
기울기 소실Vanishing gradient
층이 깊을 때 뒤에서 앞으로 기울기를 곱하다 보면 값이 0에 가까워져 앞쪽 층이 학습되지 않는 현상이에요. 시그모이드의 σ′ ≤ 0.25가 원인이에요.
포화Saturation
활성화 함수 그래프의 양끝이 평평해져서 기울기가 0에 가까운 상태예요. 시그모이드와 탄젠트에서 생겨요.
죽은 ReLUDying ReLU
입력이 계속 음수라 출력과 기울기가 0이 되어 뉴런이 더 이상 배우지 못하는 현상이에요.
He 초기화He initialization
ReLU 계열 층의 가중치를 처음에 어떤 크기로 시작할지 정하는 방법이에요. Sigmoid·Tanh에는 Xavier를 짝지어요.
가중치 초기화Weight initialization
학습을 시작할 때 가중치를 어떤 값으로 놓을지 정하는 일이에요. 모두 같은 값으로 시작하면 뉴런이 똑같이 움직여서 안 돼요.
역전파Backpropagation
손실의 기울기를 출력층에서 입력층 방향으로 Chain Rule로 곱해 전달하며 모든 가중치의 기울기를 구하는 과정이에요.
Chain RuleChain Rule
함수 안에 함수가 들어 있을 때 바깥 미분과 안쪽 미분을 곱해 미분하는 규칙이에요. 역전파는 이걸 층마다 뒤에서부터 곱해 나가요.
과적합Overfitting
학습 데이터는 잘 맞히는데 새 데이터에서는 성능이 떨어지는 현상이에요. 학습 손실은 내려가는데 검증 손실이 다시 오르는 것이 신호예요.
과소적합Underfitting
학습 데이터조차 잘 못 배워서 학습·검증 모두 성능이 낮은 상태예요. 모델을 키우거나 더 오래 학습해야 해요.
일반화Generalization
처음 보는 새 데이터에서도 잘 맞히는 능력이에요. 과적합은 이 능력이 떨어진 상태예요.
정규화 (규제)Regularization
모델이 학습 데이터를 너무 외우지 못하게 방해해서 과적합을 줄이는 방법들이에요. L1, L2, Dropout, BatchNorm, 데이터 증강, 조기 종료가 있어요.
L1L1 (Lasso)
손실에 가중치 절댓값의 합 λΣ|w|를 더해요. 일부 가중치를 정확히 0으로 만들어서 변수 선택 효과가 있어요.
L2L2 (Ridge)
손실에 가중치 제곱의 합 λΣw²를 더해요. 가중치가 너무 커지지 않게 눌러 줘요.
Weight DecayWeight Decay
L2와 같은 일을 하는 옵티마이저 옵션이에요. 매번 가중치를 조금씩 줄여서 커지는 것을 막아요.
DropoutDropout
학습할 때 뉴런을 확률적으로 꺼 버리는 방법이에요. 특정 뉴런에 의존하지 못하게 해서 앙상블 같은 효과를 내요. 추론 때는 전부 켜요.
Batch NormalizationBatch Normalization
각 층의 입력을 평균 0, 분산 1로 맞춰 주는 방법이에요. 기울기가 폭주하거나 사라지는 것을 줄이고 학습 속도를 높여 줘요.
데이터 증강Data Augmentation
사진을 돌리거나 자르는 식으로 학습 데이터를 인위적으로 늘리는 방법이에요. 한 모양만 외우지 않게 해요.
조기 종료Early Stopping
검증 손실이 더 이상 개선되지 않으면 학습을 멈추는 방법이에요. 가장 싸고 확실한 정규화예요.
Label SmoothingLabel Smoothing
정답 원-핫 라벨을 [0.9, 0.05, 0.05]처럼 약간 퍼지게 해서 모델이 너무 자신하지 않게 하는 방법이에요.
앙상블Ensemble
여러 모델의 의견을 모아 결정하는 방법이에요. Dropout은 매번 다른 작은 네트워크를 학습해서 앙상블과 비슷한 효과를 내요.
KerasKeras
신경망을 조립식 블록처럼 쉽게 만들게 해 주는 파이썬 도구예요. 층, 손실, 옵티마이저를 객체 하나씩으로 다뤄요.
TensorFlowTensorFlow
구글이 만든 딥러닝 도구예요. Keras가 이 안에 들어 있어서 tf.keras로 써요.
SequentialSequential
층을 위에서 아래로 차례로 쌓는 가장 기본적인 Keras 모델이에요.
compilecompile
학습 설정을 정하는 단계예요. optimizer(어떻게 갱신), loss(무엇을 줄일지), metrics(무엇을 볼지) 세 가지를 정해요.
fitfit
학습을 실제로 돌리는 호출이에요. 학습 루프와 자동 미분(역전파)을 알아서 해 줘요.
evaluateevaluate
테스트 데이터로 점수를 재는 호출이에요. compile에서 정한 loss와 metrics를 순서대로 돌려줘요.
predictpredict
새 데이터의 예측을 내는 호출이에요. 분류 모델이면 클래스별 확률 벡터를 돌려줘요.
argmaxargmax
여러 값 중 가장 큰 값이 있는 번호를 알려 주는 함수예요. 확률 벡터에서 예측 클래스를 뽑을 때 써요.
콜백Callback
학습 도중 정해진 때(epoch 끝 등)에 자동으로 불리는 도우미예요. EarlyStopping이 대표적이고 fit(callbacks=[...])에 연결해요.
historyHistory
fit이 돌려주는 기록이에요. epoch마다 loss, accuracy, val_loss, val_accuracy가 리스트로 들어 있어서 학습 곡선을 그릴 때 써요.
MNISTMNIST
28×28 흑백 손글씨 숫자 70,000장 데이터예요. 딥러닝의 '안녕, 세상아' 같은 연습 데이터예요.
NumPyNumPy
숫자 계산용 파이썬 도구예요. 2장에서 뉴런과 경사하강을 직접 만들 때 썼어요.
epochEpoch
학습 데이터 전체를 한 바퀴 다 쓰는 것이 1 epoch이에요. 문제집을 처음부터 끝까지 한 번 푼 것과 같아요.
batchBatch
한 번에 같이 보는 샘플의 묶음이에요. batch_size=128이면 한 번에 128장을 보고 가중치를 한 번 고쳐요.
batch_sizebatch_size
배치 하나에 들어가는 샘플 수예요. 키우면 epoch당 갱신 횟수(step)가 줄어요.
stepStep
배치 하나로 가중치를 한 번 갱신하는 것이에요. 55,000장을 128장씩 보면 1 epoch이 430 step이에요.
EarlyStoppingEarlyStopping
Keras의 조기 종료 콜백이에요. monitor, patience, restore_best_weights 세 인자가 핵심이에요.
patiencepatience
개선이 없어도 몇 epoch까지 기다려 줄지 정하는 값이에요. 3이면 최고 기록 뒤 연속 3번 못 넘으면 멈춰요.
monitormonitor
EarlyStopping이 매 epoch 끝에 지켜볼 지표예요. 'val_loss'나 'val_accuracy'처럼 이름으로 적어요.
restore_best_weightsrestore_best_weights
멈출 때 마지막이 아니라 가장 성적이 좋았던 시점의 가중치로 되돌릴지 정하는 옵션이에요. 보통 True로 둬요.
min_deltamin_delta
이만큼은 좋아져야 '개선'으로 쳐 주겠다는 최소 기준이에요. 작은 요동을 개선으로 착각하지 않게 해요.
modemode
monitor 값이 클수록 좋은지('max') 작을수록 좋은지('min')를 정하는 옵션이에요. 정확도는 max, 손실은 min이에요.
validation_datavalidation_data
fit에 검증 데이터를 넘기는 인자예요. 이게 있어야 val_loss, val_accuracy가 계산돼서 콜백이 볼 수 있어요.
val_lossval_loss
검증 데이터에서 잰 손실이에요. 학습 손실은 내려가는데 이게 다시 오르면 과적합 신호예요.
val_accuracyval_accuracy
검증 데이터에서 잰 정확도예요. 순위만 보기 때문에 val_loss보다 과적합을 늦게 알려 줘요.
ReduceLROnPlateauReduceLROnPlateau
개선이 멈추면 학습률을 factor만큼(0.5면 절반) 줄여 주는 콜백이에요.
ModelCheckpointModelCheckpoint
가장 좋았던 모델을 파일로 저장해 두는 콜백이에요. save_best_only=True로 써요.
verboseverbose
학습 로그를 얼마나 보여 줄지 정하는 값이에요. 1은 진행 막대, 2는 epoch당 한 줄, 0은 조용히예요.
