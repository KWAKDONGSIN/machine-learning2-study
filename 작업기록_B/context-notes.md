# 결정과 이유 (계속 추가)

- 범위 기준은 `머신러닝2_중간고사_학습키워드.pdf`. 객관식 25 · 단답 2(3장 Keras 코드 빈칸) · 주관식 2(그래프 해석, 개념 응용). 계산기 없이 정수 계산(파라미터 수, step 수, 혼동행렬 지표)은 나온다. 시그모이드·로그 수치 손계산은 안 나온다.
- 숫자·정의는 강의 PDF(chapter2 p.18–21·30–33·35–36·55–57, chapter3 p.1–28) 기준.
- **교수님 정정(10/19 녹취 07)** — chapter3 17쪽의 "조기 종료 발동 안 함"은 오기이고 실제로는 발동했다. 6주차 수업 화면 로그는 최고 0.9834 뒤 3번 못 넘어 정지, 최종 0.9834. PDF 표의 epoch 숫자(12/15/18)와 어긋나므로 c9에서는 "교수님이 발동했다고 정정" 한 줄만 쓰고 epoch 번호는 확정해서 쓰지 않는다.
- 교수님이 6주차에 '256의 배치', 검증 '500장' 등으로 잘못 읽은 것은 PDF 기준(은닉 256개, 검증 5,000장, batch 128)으로 쓴다.
- 10/19 녹취에서 교수님이 강조한 것 — 정밀도 분모(TP+FP)와 재현율 분모(TP+FN)를 단순 암기하지 말고 의미로 구분, 원-핫 라벨은 이진이 아니다(categorical), 정수 라벨은 sparse, Dropout 때문에 첫 epoch에 학습 정확도 < 검증 정확도, 입력층 직후 Dropout은 작게, 객관식에도 그래프 문제가 나온다.
- 활성화 함수 그래프는 강의 PDF에 곡선 그림이 없고(표만 있음) 도함수 그림만 p.48에 있다. 그래서 c6은 인라인 SVG로 Sigmoid·Tanh·ReLU 곡선을 직접 그리고 p.30·31·48 슬라이드 사진을 곁들인다.
- 코드 빈칸 연습은 정답 철자를 그대로 쓴다. 문자열은 따옴표 포함.
- 환경에 tensorflow가 없어 Keras 코드는 실행 검증 불가. 대신 파라미터 수·step 수·EarlyStopping 시뮬레이션·혼동행렬 지표는 파이썬으로 재계산해서 본문 숫자와 대조한다.
- 파일 첫 줄 `<!-- ... -->` 한국어 설명(규칙 6 충족). chapters_B.json은 주석이 불가능해 제외.
- git 저장소가 아니어서 커밋은 하지 않는다.
- 슬라이드 사진은 chapter2 p.19·20·21·30·31·48·55·57, chapter3 p.4·11·13·19·22·24·26·27에서 떴다(b_*.jpg 16장). 장마다 3~4장.
- 본문 초안과 SVG 생성 스크립트는 세션 임시 폴더에만 있다. 수정이 필요하면 content/easy/c5~c9.html을 직접 고친다(SVG는 파일 안에 인라인으로 들어 있다).
- 숫자 검증은 파이썬으로 했다 — c5 지표(0.85·0.75·0.6·2/3, 슬라이드 예 0.9·0.5·0.9·0.64), 3×3(정확도 5/7, 개 P 3/4 R 3/5), c8 파라미터(203,530·407,050·101,770·109,386·195), c9 step(430·1,719·108·704·313)과 EarlyStopping 시뮬레이션 5문항 정답.
- 검증하지 못한 것 — Keras 코드 실제 실행(tensorflow 미설치), 사이트 CSS 렌더링(템플릿이 content 폴더에 없음). 휴대폰 폭에서 SVG 글자가 읽히도록 viewBox를 좁게 잡고 임시 CSS로만 확인했다.
- c9 EarlyStopping 연습에서 epochs 최대치가 '최고 epoch + patience'보다 작은 경우는 "끝까지 돈다"까지만 쓰고 가중치 복원 여부는 쓰지 않았다(Keras 버전별로 동작이 달라 불확실).
- 다른 장과의 연결 — c4가 학습률·step/epoch를 이미 짧게 다룬다. c7은 곡선 네 패턴 진단을 주관식 답안 틀까지 확장했고, c9는 step 계산과 EarlyStopping 시뮬레이션에 집중했다.
