# 결정과 이유 (본문 A)
- 녹취 번호 대응: 머신러닝01=1주차(9/7 OT) · 머신02=2주차(9/14, Ch1 본진도) · 머신러닝03=3주차(9/21, Ch2) · 머신러닝04=4주차(9/28, Ch2 후반) · 머신러닝06=6주차(10/12, Ch3) · 머신러닝07=7주차(10/19, 중간고사 복습). 5주차는 개천절 대체공휴일 휴강. 바탕화면 녹취와 녹음파일본 폴더의 파일 크기가 같아서 확인함.
- 숫자 기준은 강의자료 PDF. 단 Chapter1 PDF 슬라이드 18·23·32에 적힌 코드 실행 결과(긴 소수)는 실제로 돌려 보면 다르다(softmax 0.659/0.242/0.099, CE 0.4155, 한 스텝 w=[0.52,-0.47,0.71]). 본문은 실제 실행값을 쓰고 한 줄로 밝힘. 시험은 손계산 수치를 안 낸다고 교수님이 명시.
- 시험 직결 항목은 키워드 PDF 표의 "이렇게 할 수 있어야 한다" 문장을 소단원의 점검 질문으로 옮김.
- 학습 곡선 네 패턴(과소/적절/과적합/학습률 과대)은 다른 장 담당이 있을 수 있어, c4에서는 학습률 진단 중심으로 쓰고 D(학습률 과대) 패턴만 슬라이드로 연결.
- HTML 클래스는 작성안내 목록만 사용. 별표는 클래스 없이 본문 글자로만.
- 파라미터 수 예제는 PDF의 784→256→10(203,530), 4→5→3(43), 입력 784→512(401,920), 128 유닛(101,770), 512 유닛(407,050)을 기준으로 하고 직접 만든 예제는 파이썬으로 재계산.
- 용어 규칙: 본문의 "N장"은 이 사이트의 장 번호(c0~c4), 강의 PDF는 "Chapter N"으로 구분해 적음.
- 강의 슬라이드 오류 3건을 본문에 한 줄로 밝힘 — (1) Ch1 p8 b=0일 때 z=0.2/0.55는 계산하면 0.4/0.60, (2) p18·p23 코드 결과 소수, (3) p32 한 스텝 결과. 모두 직접 실행·계산한 값을 사용.
- 슬라이드 도식 대신 직접 만든 인라인 SVG 6개(산 내려가기, −log p 곡선, 뉴런, 편향 평행 이동, 4→5→3 파라미터, 학습률별 손실 곡선).
- 검증: 태그 균형·허용 클래스·이모지·콜론 끝 문장·이미지 경로·소단원별 시험 박스/잠깐 확인·그림 4장 이하를 스크립트로 확인하고 모바일 폭(450px)에서 SVG를 눈으로 확인함. (★는 예시 사이트와 같이 평문 기호로 사용)
