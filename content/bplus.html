교수님 정정 (7주차)

3장 슬라이드 17쪽의 "조기종료 발동 안 함"은 틀린 표기라고 교수님이 직접 고쳤어요. patience 3이면 최고 뒤 3번 연속 못 넘을 때 발동하는 것이 맞아요. 시험에는 이 규칙으로 풀면 돼요.

④ 정수 계산 3종 풀이 15분

손계산은 곱하기 · 나누기 정도예요. 공식 3개만 외우고 순서대로 대입하세요.

가) 파라미터 수 — 입력 × 출력 + 출력

Dense 층 하나는 입력 수 × 출력 수 + 출력 수예요. 마지막 "+ 출력 수"는 뉴런마다 하나씩인 편향이에요. Flatten과 Dropout은 학습할 값이 없어서 0개예요. 층마다 구해서 더해요.

모델층별 계산합계
784 → 256 → 10784×256+256 = 200,960 · 256×10+10 = 2,570203,530
784 → 128 → 10784×128+128 = 100,480 · 128×10+10 = 1,290101,770
784 → 512 → 10784×512+512 = 401,920 · 512×10+10 = 5,130407,050
4 → 5 → 34×5+5 = 25 · 5×3+3 = 1843
784 → 128 → 64 → 10100,480 · 128×64+64 = 8,256 · 64×10+10 = 650109,386

곱셈이 막히면 784 × 256 = 784 × 200 + 784 × 56 = 156,800 + 43,904 = 200,704 처럼 쪼개요. 편향을 빼먹은 값(200,704)이 단골 오답 보기예요.

나) step 수 — 샘플 수 ÷ batch_size, 올림

1 epoch의 step 수는 ⌈학습 샘플 수 ÷ batch_size⌉예요. 나눠떨어지지 않으면 남은 샘플로 만든 작은 배치도 한 번 갱신하니까 무조건 올림이에요.

학습 샘플 · batch_size계산step / epoch
55,000 · 12855,000 ÷ 128 = 429.69…430 (로그의 430/430)
55,000 · 321,718.75…1,719
55,000 · 512107.42…108
20,000 · 25678.12579

전체 갱신 횟수는 step × epoch예요. 430 × 20 = 8,600번이에요. 배치를 키우면(128 → 512) step이 줄어서(430 → 108) 같은 epoch 수로는 덜 학습돼요.

EarlyStopping 시뮬레이션 한 줄

멈추는 epoch = 최고 epoch + patience. 최고가 epoch 7, patience 3이면 10 epoch 끝에 멈춰요. restore_best_weights=True면 최종 가중치는 epoch 7의 것이고, False면 10의 것이에요. 도중에 최고를 새로 세우면 세던 횟수는 0으로 돌아가요.

다) 혼동행렬 지표 — 행 = 실제, 열 = 예측

이름의 앞 글자(True/False)는 맞았나, 뒷글자(Positive/Negative)는 뭐라고 예측했나예요. FN은 "음성이라고 했는데 틀림", 즉 실제 양성을 놓친 거예요.

지표식분모가 뜻하는 것
Accuracy(TP + TN) / 전체전체 샘플
PrecisionTP / (TP + FP)모델이 양성이라고 한 것 전부 (열 방향)
RecallTP / (TP + FN)진짜 양성 전부 (행 방향)
F12PR / (P + R)조화평균

예시 TP = 30, FP = 10, FN = 20, TN = 140이면 Accuracy = 170/200 = 0.85, Precision = 30/40 = 0.75, Recall = 30/50 = 0.6이에요.

3×3은 그 클래스를 양성, 나머지를 음성으로 놓아요. 행 = 실제, 열 = 예측일 때 '개'를 봐요.

실제 \ 예측고양이개새행 합계
고양이81110
개26210
새02810
열 합계1091130

개의 TP = 6이에요. Precision은 열 합계 9로 나눠 6/9 ≈ 0.67이고, Recall은 행 합계 10으로 나눠 6/10 = 0.6이에요. 전체 Accuracy는 대각선 8 + 6 + 8 = 22 → 22/30이에요.

이렇게 고르세요

① 유병률 10%에서 "모두 음성"이라고 답하는 모델은 Accuracy 0.9, Recall 0. ② 암 검진은 Recall(놓침 FN이 치명적), 스팸 차단은 Precision(정상 메일을 막는 FP가 아픔), 부정 거래는 F1 + 임계값 조정. ③ 임계값을 낮추면 Recall↑ Precision↓, 높이면 반대예요.

⑤ 그래프 4패턴 진단표 10분

학습·검증 곡선은 반드시 두 줄을 같이 봐요. 한 줄(학습 손실)만 보면 과적합이 안 보여요. 객관식에도, 주관식에도 나오는 표예요.

val_loss vs val_accuracy

정확도는 순위(argmax)만 보고, 손실은 확률의 품질(과신)까지 봐요. 그래서 val_loss가 과적합을 더 일찍 드러내요. MNIST에서 val_accuracy 최고는 epoch 18, val_loss 최소는 epoch 13이었어요. 첫 epoch에 학습 정확도가 검증보다 낮은 것은 Dropout 때문이에요(학습 때만 끄고 추론 때는 전부 켬).

⑥ 주관식 답안 틀 2개 15분

주관식 30점은 틀에 맞춰 쓰면 부분점수가 확실히 나와요. 가리고 종이에 한 번씩 써 보세요.

틀 1. 그래프 해석 — 현상 이름 → 근거 → 처방

① 현상 "이 곡선은 ○○이다." → ② 근거 "학습 손실은 ~하고 검증 손실은 ~해서, 두 곡선의 간격이 ~하다." → ③ 처방 "~한다. EarlyStopping은 monitor / patience / restore_best_weights를 정해서 쓴다."

예시 문제 — 학습 손실은 계속 줄지만 검증 손실은 epoch 6에서 최소가 된 뒤 다시 올라간다.

(1) 과적합이다. (2) 학습 손실은 계속 감소하는데 검증 손실은 epoch 6 이후 증가하고 두 곡선의 간격이 벌어진다. 모델이 학습 데이터(와 노이즈)를 외워 새로운 데이터에 일반화하지 못한다는 뜻이다. (3) 검증 손실이 최소인 epoch 6 부근에서 EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True)으로 멈추면 9 epoch 끝에 멈추고 epoch 6의 가중치로 복원된다. 추가로 Dropout, L2, 데이터 증강 · 추가, 은닉 유닛 축소를 쓴다.

나머지 패턴(과소적합 · 학습률 과대)은 ⑤의 표를 그대로 옮겨 쓰면 돼요. 더 연습은 서술형 14개에 있어요.

틀 2. 개념 응용 — 상황 → 출력층 · 지표 · 임계값 · 전처리

① 문제 유형(이진 / 다중 / 멀티라벨 / 회귀) → ② 출력층(뉴런 수 · 활성화 · 손실) → ③ 지표(FN과 FP 중 비싼 쪽) → ④ 임계값(낮춤 / 높임) → ⑤ 전처리(정규화 · 표준화 · 누수 방지). 각 칸에 "왜냐하면"을 한 줄씩 붙여요.

예시 문제 — 환자 10%인 암 검진 데이터로 양성/음성을 가르는 신경망.

(1) 이진 분류이므로 출력 뉴런 1개, Sigmoid, Binary Cross-Entropy를 쓴다. (2) 환자가 10%뿐이라 모두 음성이라 해도 정확도가 90%가 나오는 함정이 있어 정확도만으로는 부족하다. 암을 놓치는 FN이 치명적이므로 Recall을 우선하고 Precision과 혼동행렬을 함께 본다. (3) 임계값은 0.5보다 낮춰(예 0.3) 양성 판정을 늘려 Recall을 높인다. FP는 재검사로 감당한다. (4) 입력은 표준화하되 학습셋 통계로만 fit하고(누수 방지), 검증셋은 EarlyStopping에 쓰며 테스트는 마지막에 한 번만 쓴다.

"모델이 학습을 잘 못 했다. 해결 방법을 아는 대로 써라" 같은 문제는 지난 학기에 "데이터를 추가한다"만 써도 점수를 줬대요. 아는 처방을 빈칸 없이 다 쓰세요.
