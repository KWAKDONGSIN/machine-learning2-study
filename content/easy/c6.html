활성화 함수 — 층을 쌓는 의미를 만드는 꺾임

뉴런의 가중합 뒤에 붙는 작은 함수가 활성화 함수예요. 이것이 없으면 층을 아무리 쌓아도 직선 하나가 돼요. 이 장에서는 왜 필요한지, Sigmoid·Tanh·ReLU를 그래프만 보고 구분하는 법, 기울기가 사라지는 이유, 그리고 출력층 활성화가 손실과 세트인 이유를 익혀요.

6-1. 왜 필요한가 — 선형 ∘ 선형 = 선형 ★

뉴런 하나는 먼저 가중합 z = w·x + b를 계산해요. 이것은 x에 숫자를 곱하고 더하는 1차식, 즉 선형(직선)이에요. 그 뒤에 활성화 함수를 붙여서 값을 한 번 비틀어 줘요.

그런데 활성화 함수 없이 가중합만 두 층 쌓으면 어떻게 될까요? 숫자로 확인해 봐요. 첫 층이 z₁ = 2x + 1이고, 둘째 층이 z₂ = 3·z₁ + 2예요.

둘째 층에 첫 층을 넣으면 3·(2x+1)+2 = 6x + 3 + 2 = 6x + 5가 돼요. 이것도 그냥 직선 하나예요. 층이 2개가 아니라 100개여도 결과는 같아요.

행렬로 쓰면 식이 이렇게 돼요. a = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W′x + b′ 이고, W′와 b′는 그냥 새로운 숫자일 뿐이에요.

한 줄 정의

선형 ∘ 선형 = 선형. 활성화 함수가 없는 Dense를 여러 층 쌓아도 결국 "선형 분류기 하나"와 같아요.

비유 — 확대 복사기

2배 확대 복사기에 3배 확대 복사기를 이어 붙여도 결국 6배 복사기 한 대일 뿐이에요. 층을 쌓는 의미가 없어요. 중간에 "구부리거나 꺾는" 장치를 끼워야 복사기를 이어 붙인 효과가 생겨요. 그 장치가 활성화 함수예요.

왜 직선 하나가 문제일까요? 세상의 문제는 직선 하나로 가를 수 없는 경우가 많아요(대표적인 예가 XOR이고, 이 예는 시험 범위가 아니에요). 비선형 함수를 층 사이에 끼우면 그때마다 공간이 구부러져서, 층을 쌓을수록 더 복잡한 모양을 만들 수 있어요.

또 하나, 활성화 함수는 학습 때 기울기가 흐르는 방식을 정해요. 그래서 학습의 안정성과 속도도 활성화 함수에 크게 좌우돼요(6-3에서 봐요).

시험엔 이렇게 써요

활성화 함수가 없으면 선형 함수를 여러 번 합성해도 결과가 하나의 선형 함수 W′x+b′가 되므로, 은닉층을 쌓는 의미가 사라지고 모델이 선형 분류기 하나와 같아진다. 따라서 은닉층에는 비선형 활성화 함수가 필요하다.

잠깐 확인 — 활성화 함수 없이 Dense 3층을 쌓으면 어떤 모델이 되나요?

선형 모델 하나(W′x + b′)와 같아져요. 층을 쌓은 보람이 없어요.

시험에는 이름 없는 그래프를 보여 주고 "이것은 무슨 함수인가", "범위는 얼마인가"를 묻는 문제가 나와요. 세 함수의 모양을 눈에 익혀요.

  • 곡선이 S자이면 Sigmoid 아니면 Tanh이고, 꺾인 직선이면 ReLU예요.
  • S자일 때는 세로축 눈금을 봐요. 0에서 1까지이고 x=0에서 0.5이면 Sigmoid, −1에서 1까지이고 원점을 지나면 Tanh예요.

비유 — 문턱과 수도꼭지

Sigmoid와 Tanh는 점점 열리다가 끝까지 열리면 더 안 나오는 수도꼭지예요. Sigmoid는 "잠김(0) ~ 활짝(1)", Tanh는 "뒤로(−1) ~ 앞으로(+1)"예요. ReLU는 문턱이 있는 문이에요. 음수 신호는 막고 양수 신호는 그대로 통과시켜요.

교수님은 "시그모이드는 x축 끝으로 가면 1 또는 0으로 가니까 이진 분류처럼 생겼다"고 했어요. 확률(0~1)처럼 읽기 좋은 이유예요. 그리고 ReLU는 우리가 쓰는 MLP의 Dense 층 기본값이라고 강조했어요.

외우기 팁

범위를 숫자 세 쌍으로 외워요. Sigmoid 0~1, Tanh −1~1, ReLU 0~무한이에요. 기울기 최대값은 Sigmoid 0.25, Tanh 1, ReLU 1(양수 구간)이고요.

시험엔 이렇게 써요

Sigmoid는 출력 범위가 (0, 1)이고 확률 해석에 적합하지만 양끝에서 기울기가 소실된다. Tanh는 범위가 (−1, 1)이고 0 중심이다. ReLU는 max(0, x)로 양의 구간 기울기가 1이고 음의 구간 기울기가 0이며 은닉층 기본값이다. (객관식 요령) 그래프가 S자이면 세로축 범위로, 꺾인 직선이면 ReLU로 고른다.

잠깐 확인 — x = 0에서 0.5를 지나는 S자 곡선은 무엇인가요?

Sigmoid예요. 1/(1+e⁰) = 1/2이라서 x=0에서 0.5가 돼요. Tanh는 x=0에서 0이에요.

6-3. 포화와 기울기 소실 ★

Sigmoid와 Tanh 그래프를 다시 봐요. 가운데는 가파르게 오르지만 양끝으로 가면 평평해져요. 입력의 크기가 커서 곡선이 평평해진 상태를 포화(saturation)라고 해요. 평평하다는 것은 기울기가 거의 0이라는 뜻이에요.

기울기가 왜 중요할까요? 학습은 "기울기만큼 가중치를 고치는" 일이에요(4장에서 배운 경사하강). 기울기가 0이면 고칠 힘이 없어서 학습이 멈춰요.

한 줄 정의

기울기 소실(vanishing gradient) = 역전파로 거꾸로 전달되는 기울기가 층을 지날수록 0에 가까워져서 앞쪽 층이 학습되지 않는 현상.

숫자로 보면 더 확실해요. Sigmoid의 기울기 σ′(x) = σ(x)(1 − σ(x))는 x = 0에서 최대 0.25이고 그보다 큰 값은 없어요(σ′ ≤ 0.25). |x|가 4쯤만 돼도 거의 0이에요.

역전파는 층마다 이 값을 곱해서 앞으로 전달해요(7장에서 자세히 봐요). 그러면 이렇게 줄어요.

비유 — 귓속말 전달 게임

맨 뒤 사람이 "정답과 다르다!"는 오차 신호를 앞 사람에게 귓속말로 전해요. 그런데 한 사람 지날 때마다 소리가 4분의 1로 줄어요. 10명째에는 거의 안 들려서 맨 앞 사람(입력층 쪽)은 고쳐야 할 것을 모르게 돼요. 이것이 기울기 소실이에요.

왜 Tanh도 문제일까요? Tanh의 기울기는 최대 1이라 Sigmoid보다 낫지만, 큰 |x|에서 포화되어 0에 가까워지는 점은 똑같아요. 둘 다 "포화형"이라서 은닉층에 여러 개 쌓으면 같은 병에 걸려요.

ReLU는 어떻게 해결할까요? 양수 구간의 기울기가 정확히 1이라 몇 번을 곱해도 줄지 않아요. 그래서 딥러닝의 표준 은닉층 활성화가 됐어요.

시험엔 이렇게 써요

Sigmoid는 도함수가 최대 0.25(σ′ ≤ 0.25)이고 양끝에서 포화되어 0에 가까워진다. 역전파에서는 층마다 이 값이 곱해지므로 층이 깊을수록 앞쪽 층의 기울기가 급격히 작아져 학습이 안 되는데, 이를 기울기 소실이라 한다. ReLU는 양수 구간의 기울기가 1이라 기울기가 줄지 않아 이 문제를 완화한다.

잠깐 확인 — Sigmoid 은닉층을 깊게 쌓으면 어느 쪽 층이 가장 학습이 안 되나요?

입력에 가까운 앞쪽 층이에요. 기울기가 뒤에서 앞으로 전달되며 0.25가 계속 곱해지니까 앞으로 갈수록 작아져요.

6-4. ReLU와 죽은 뉴런 ★

ReLU는 max(0, x)예요. 입력이 음수이면 0, 양수이면 그대로 내보내요. 식의 뒤쪽 0이 중요해요. "음수는 0으로 막는다"는 뜻이에요.

  • 양수 구간 기울기 = 1, 음수 구간 기울기 = 0 (교수님이 "외우라"고 한 부분이에요)
  • 계산이 아주 간단해서 빨라요(0과 비교 한 번).
  • 포화가 없어서 기울기 소실이 적어요.

그런데 음수 구간 기울기가 0이라는 것이 약점이에요. 어떤 뉴런의 가중합이 항상 음수가 되도록 가중치가 한 번 크게 밀리면, 출력은 항상 0이고 기울기도 0이라 가중치가 다시는 고쳐지지 않아요. 이렇게 영원히 신호가 안 나오는 뉴런을 죽은 뉴런(dead ReLU)이라고 해요.

비유 — 잠긴 문

ReLU는 음수 쪽 문이 잠겨 있는 방이에요. 방 안 사람(뉴런)이 한 번 잠긴 쪽으로 밀려 들어가면, 문을 두드려 줄 신호(기울기)도 0이라서 영원히 갇혀요. 학습률을 너무 크게 하거나 초기값이 나쁘면 이런 일이 잘 생겨요.

처방은 이렇게 해요.

  • Leaky ReLU — 음수 구간에서 기울기를 완전히 0으로 두지 않고 아주 작게(예 0.01x) 남겨요. leak은 "물이 샌다"는 뜻이에요. 비용은 ReLU와 거의 같아요.
  • ELU, PReLU 같은 변형도 있어요. PReLU는 음수 쪽 기울기를 학습으로 정해요.
  • He 초기화 — ReLU 계열은 He(Kaiming) 초기화와 함께 써요. 초기값이 너무 크면 출력과 기울기가 폭주하고, 너무 작으면 0에 가까워져요.

그 밖에 최신 모델에서는 Swish(SiLU, x·σ(x))와 GELU를 써요. Transformer 계열은 GELU가 표준이에요. 이 둘은 이름과 "ReLU보다 매끄럽고 성능이 종종 좋다" 정도만 알면 돼요.

외우기 팁

은닉층 기본 순서는 "ReLU + He 초기화로 시작 → 죽은 뉴런이 많으면 Leaky ReLU/ELU → 더 높은 성능이 필요하면 Swish/GELU"예요. 문제가 생길 때만 바꿔요.

시험엔 이렇게 써요

ReLU는 max(0, x)로 양수 구간 기울기 1, 음수 구간 기울기 0이다. 음수 구간에서 기울기가 0이므로 가중치가 갱신되지 않는 죽은 뉴런(dead ReLU)이 생길 수 있고, 이를 Leaky ReLU 등으로 완화한다. MLP 은닉층에는 ReLU를 기본값으로 쓴다.

잠깐 확인 — "죽은 뉴런"은 왜 계속 죽어 있나요?

출력이 항상 0이고 음수 구간의 기울기도 0이어서 가중치를 고칠 신호가 전혀 오지 않기 때문이에요.

6-5. 출력층 활성화는 손실과 세트 ★★

은닉층 활성화(ReLU 등)와 출력층 활성화는 역할이 달라요. 은닉층은 모양을 구부려 표현력을 만드는 일을 하고, 출력층은 "무엇을 예측하는가"에 맞는 모양의 값을 내보내요. 교수님은 이 표가 "중간·기말에도 계속 따라다닌다"고 했어요.

왜 Softmax와 Sigmoid를 나눌까요? Softmax는 모든 출력의 합이 1이 되게 만들어요. "여러 후보 중 하나"를 고르는 문제에 맞아요. Sigmoid는 출력마다 따로 0~1을 내서 "각각 켜졌나 꺼졌나"를 독립적으로 말해요. 한 사진에 고양이도 있고 강아지도 있는 멀티라벨이 그 예예요.

  • "이 사진은 숫자 0~9 중 무엇인가" → 정답 하나, 합 1 → Softmax
  • "이 영화 리뷰는 긍정인가" → 예/아니오 → Sigmoid (뉴런 1개)
  • "이 사진에 있는 태그를 모두 고르시오" → 각각 독립 → Sigmoid (뉴런 여러 개)
  • "내일 기온은 몇 도인가" → 숫자 → Linear

Linear는 입력을 그대로 내보내는 함수예요. 이것도 활성화 함수의 하나예요. "은닉층에 선형을 쓰면 안 된다"는 말과 헷갈릴 수 있는데, 금지된 것은 은닉층의 선형이고 출력층의 회귀용 Linear는 별개예요(6-1). 값의 범위가 정해진 회귀(예 −1~1)는 Tanh 또는 Sigmoid에 크기를 맞춰 쓰기도 해요.

외우기 팁

"하나 고르기 = Softmax, 각각 켜기 = Sigmoid, 숫자 맞히기 = Linear"예요. 손실은 짝꿍이라 활성화를 알면 따라 나와요. Softmax는 categorical, Sigmoid는 binary, Linear는 MSE예요. 정수 라벨일 때 sparse_가 붙는 것은 8장에서 다뤄요.

교수님이 예고한 출제 방식은 두 가지예요. 하나는 데이터 설명을 주고 "보기가 tanh, ReLU, Swish, Sigmoid일 때 이진 분류의 출력층은?"처럼 활성화를 고르게 하는 것이에요. 다른 하나는 "Softmax를 넣었다면 데이터는 어떤 형식일까요?"처럼 거꾸로 묻는 것이에요.

시험엔 이렇게 써요

출력층 활성화는 손실 함수와 세트로 문제 유형이 정한다. 이진 분류와 멀티라벨은 Sigmoid + Binary Cross-Entropy, 다중 클래스(정답 하나)는 Softmax + Categorical Cross-Entropy, 회귀는 Linear + MSE이다. Softmax는 출력의 합이 1이 되어 하나의 클래스를 고르는 문제에 맞고, Sigmoid는 클래스마다 독립 확률을 낸다.

잠깐 확인 — 한 사진에 "사람, 자동차, 신호등"이 동시에 있는지를 각각 맞히는 모델의 출력층은?

멀티라벨 문제라서 Sigmoid(라벨 수만큼 뉴런) + Binary Cross-Entropy예요. Softmax는 합이 1이라 하나만 고르게 만들어서 맞지 않아요.

6-6. 연습 문제 — 그래프와 개념으로 풀어 봐요

문제 1. 아래 이름 없는 세 그래프의 이름을 순서대로 쓰세요.

정답 보기

① Tanh (−1~1, 원점 통과), ② ReLU (음수는 0, 위로 끝없이 올라감), ③ Sigmoid (0~1, x=0에서 0.5)예요.

문제 2. 다음 중 Sigmoid에 대한 설명으로 틀린 것은?

  • ① 출력 범위가 (0, 1)이다
  • ② 도함수의 최대값이 0.25이다
  • ③ 양끝에서 기울기가 0에 가까워진다
  • ④ 음수 입력에서는 항상 0을 출력한다
정답 보기

④예요. 음수 입력에서 0을 내는 것은 ReLU이고, Sigmoid는 음수 입력에도 0보다 큰 작은 값(예 σ(−2) ≈ 0.12)을 내요.

문제 3. 기울기 소실이 가장 심하게 나타나기 쉬운 은닉층 구성은?

  • ① 10층 ReLU
  • ② 10층 Sigmoid
  • ③ 10층 Leaky ReLU
  • ④ 2층 ReLU
정답 보기

②예요. Sigmoid는 기울기가 최대 0.25라서 10층이면 0.25¹⁰ ≈ 10⁻⁶으로 줄어들어요. ReLU 계열은 양수 구간 기울기가 1이에요.

문제 4. 정답이 "고양이, 개, 새" 중 하나인 3개 클래스 분류의 출력층 구성은?

  • ① 뉴런 1개, Sigmoid, Binary Cross-Entropy
  • ② 뉴런 3개, Softmax, Categorical Cross-Entropy
  • ③ 뉴런 3개, Linear, MSE
  • ④ 뉴런 3개, ReLU, Binary Cross-Entropy
정답 보기

②예요. 정답이 하나인 다중 클래스는 클래스 수만큼 뉴런을 두고 Softmax와 Categorical Cross-Entropy를 써요.

문제 5. "활성화 함수가 필요한 이유를 서술하시오"에 대한 모범 답안을 써 보세요.

모범 답안 보기

활성화 함수가 없으면 가중합(선형)을 여러 층 합성해도 결과가 하나의 선형 함수 W′x + b′가 되어, 은닉층을 쌓아도 선형 분류기 하나와 다름없다. 은닉층 사이에 비선형 활성화 함수를 넣어야 층을 쌓을수록 복잡한 비선형 경계를 표현할 수 있고, 활성화 함수는 기울기 흐름을 정해 학습의 안정성과 속도에도 영향을 준다.

이 장 3줄 요약
  • 활성화 함수가 없으면 선형 ∘ 선형 = 선형이라 Dense를 100층 쌓아도 직선 하나예요. 비선형을 끼워야 층을 쌓는 의미가 생겨요.
  • Sigmoid(0~1, S자, σ′ ≤ 0.25), Tanh(−1~1, S자, 원점 통과), ReLU(max(0, x), 양수 기울기 1·음수 0)를 그래프로 구분해요. 포화형은 층마다 0.25가 곱해져 기울기 소실이 생기고, ReLU는 죽은 뉴런이 약점이라 Leaky ReLU로 완화해요.
  • 출력층 활성화는 손실과 세트예요. 이진·멀티라벨은 Sigmoid + Binary CE, 다중 클래스는 Softmax + Categorical CE, 회귀는 Linear + MSE이고 은닉층 기본값은 ReLU예요.
