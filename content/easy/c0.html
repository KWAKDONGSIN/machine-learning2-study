왕초보 수학·머신러닝 기초 — 계산은 컴퓨터가, 우리는 뜻만

이 과목에는 수식이 많이 나오지만, 시험에서 복잡한 숫자 계산을 손으로 시키지는 않아요. 그래서 이 장에서는 "이 기호가 무슨 뜻인가"만 일상 비유로 익혀요. 여기 나온 말만 알면 뒤 장의 식이 훨씬 편하게 읽혀요. 참고로 이 사이트의 "○장"은 사이트의 장 번호이고, 강의자료는 항상 "Chapter"로 적을게요.

0-1. 머신러닝이란 — 규칙을 쓰지 않고 데이터에서 배우게 하기

한 줄 정의

머신러닝(machine learning)은 사람이 규칙을 하나하나 써 주지 않고, 컴퓨터가 데이터에서 규칙(패턴)을 스스로 찾게 하는 방법이에요.

교수님은 "과거에서 패턴을 찾아 현재에 적용하고, 미래를 조금 낫게 만드는 일"이라고 설명했어요. 예전에는 점을 치던 일을 지금은 학문으로 하는 것이라는 농담도 했어요.

이 과목에서는 네 낱말만 정확히 알면 돼요.

낱말뜻식품 쪽 비유
입력 (x)모델에 넣는 재료 숫자들식품 성분표의 숫자
출력 (ŷ)모델이 내놓는 답. 숫자 하나일 수도, 확률 여러 개일 수도 있어요"이 제품은 맛있다 확률 0.8"

비유 — 배합비 맞추기

처음에는 소금 양을 아무렇게나 넣어요. 맛 평가(정답)와 비교해서 "너무 짜다"면 조금 줄이고, "싱겁다"면 조금 늘려요. 이걸 수없이 반복해서 알맞은 배합비를 찾는 것이 학습이에요.

지도학습(supervised learning)은 정답이 붙은 데이터로 배우는 방식이에요. 교수님은 "데이터 사이언티스트로 살려면 이게 제일 중요하다"고 했어요. 정답표가 없으면 모델이 뭘 틀렸는지 알 수 없기 때문이에요.

1학기 머신러닝과 딥러닝의 가장 큰 차이는 "특성(입력을 설명하는 숫자)을 누가 만드느냐"예요. 1학기에는 사람이 만들었고, 딥러닝은 뉴런을 층으로 쌓아 모델이 스스로 배워요. 그래서 딥러닝은 이미지·음성·문장 같은 표가 아닌 데이터에 강해요.

시험엔 이렇게 써요

머신러닝은 데이터에서 패턴을 학습하여 새로운 입력에 대한 예측을 하는 방법이다. 딥러닝은 뉴런을 여러 층으로 쌓아 특성을 모델이 스스로 학습한다는 점에서, 사람이 특성을 설계하던 1학기 머신러닝과 구별된다.

잠깐 확인 — "학습"을 한 문장으로 말해 보세요

정답과 비교해서 틀린 만큼 모델 안의 숫자(가중치와 편향)를 조금씩 고치는 일이에요.

0-2. 숫자 여러 개를 줄 세운 것 — 벡터

한 줄 정의

벡터(vector)는 숫자 여러 개를 한 줄로 세운 것이에요. 예를 들어 x = [2, 3, 1]은 숫자 3개짜리 벡터예요.

줄에 서 있는 숫자는 순서가 의미를 가져요. 첫 번째 칸은 "첫 번째 특성", 두 번째 칸은 "두 번째 특성"이라는 식이에요. 칸이 몇 개인지가 그 벡터의 "크기"예요.

비유 — 장바구니

장바구니에 사과 2개, 우유 3개, 빵 1개를 담았다면 [2, 3, 1]이에요. 가격표도 [1000, 2000, 500]처럼 같은 순서의 벡터로 쓸 수 있어요. 신경망에서는 입력 x와 가중치 w가 이렇게 같은 길이의 벡터로 짝을 이뤄요.

강의자료에는 ℝᵈ라는 기호가 나와요. ℝ은 "실수(소수점이 있는 보통의 숫자) 전체"이고, ℝᵈ는 "실수 d개짜리 벡터"라는 뜻이에요. 이름이 거창할 뿐 "숫자 d개를 줄 세운 것"이에요.

시험엔 이렇게 써요

입력 벡터 x는 한 샘플의 특성값을 순서대로 나열한 것이며, 가중치 벡터 w는 각 특성에 곱해지는 중요도를 같은 순서로 나열한 것이다.

잠깐 확인 — 입력이 28×28 이미지를 펼친 784개 숫자라면 벡터의 크기는?

784예요. 784개짜리 벡터이고, 강의 Chapter 3의 MNIST 실습에서 이 숫자가 다시 나와요.

0-3. 표 — 행렬

한 줄 정의

행렬(matrix)은 숫자를 가로세로 표 모양으로 늘어놓은 것이에요. 가로줄은 행, 세로줄은 열이라고 불러요.

크기는 "행 수 × 열 수"로 말해요. 아래 표는 2행 3열이라서 "2×3 행렬"이에요.

1열2열3열
1행102
2행01−1

신경망에서 가중치 행렬 W의 한 행이 뉴런 하나예요. 뉴런이 5개면 행이 5개이고, 입력이 4개면 열이 4개라서 5×4 표가 돼요. 이 크기 읽는 법이 2장의 "파라미터 수 세기"로 곧바로 이어져요.

비유 — 성적표

학생 5명이 과목 4개를 본 성적표는 5행 4열이에요. 신경망의 W는 "뉴런 5개가 입력 4개를 각각 얼마나 중요하게 보는가"를 적은 성적표 같은 거예요.

시험엔 이렇게 써요

가중치 행렬 W의 크기는 (이번 층 뉴런 수) × (앞 층 뉴런 수)이며, 행 하나가 뉴런 하나의 가중치 벡터에 해당한다.

잠깐 확인 — 3행 4열 표는 "몇 × 몇" 행렬인가요?

3×4 행렬이에요. 행 수를 먼저, 열 수를 나중에 읽어요.

0-4. 곱하고 더하기 — 가중합

신경망 계산의 거의 전부는 "같은 순서끼리 곱한 다음 전부 더하기" 하나예요. 이것을 가중합(weighted sum) 또는 내적이라고 불러요. 교수님도 "말은 거창하지만 싹 다 곱해서 싹 다 더하는 게 전부"라고 했어요.

비유 — 장바구니 합계

개수 [2, 3, 1]에 가격표 [1000, 2000, 500]를 같은 순서로 곱해서 더하면 2000 + 6000 + 500 = 8500원이에요. 이게 가중합이에요. 가격표 자리에 "얼마나 중요한가(가중치)"가 들어갈 뿐이에요.

강의자료의 예로 한 번 해 볼게요. 입력 x = [2, 3, 1], 가중치 w = [0.5, −0.2, 0.8], 편향 b = 1이에요.

z = (0.5 × 2) + (−0.2 × 3) + (0.8 × 1) + 1 = 1.0 − 0.6 + 0.8 + 1 = 2.2

표(행렬)와 벡터를 곱하는 것도 같은 일을 행마다 한 번씩 하는 거예요. 아래 2×3 표 W에 위의 x를 곱해 볼게요.

행계산결과
1행 [1, 0, 2]1×2 + 0×3 + 2×14
2행 [0, 1, −1]0×2 + 1×3 + (−1)×12

결과 [4, 2]에 편향 b = [1, −1]을 더하면 [5, 1]이에요. 뉴런이 2개인 한 층의 가중합이 이렇게 나와요. 시험에서 이런 곱셈을 시키지는 않지만, "행 하나 = 뉴런 하나가 곱하고 더한다"는 그림만 머리에 있으면 돼요.

시험엔 이렇게 써요

가중합 z = wᵀx + b는 입력의 각 성분에 가중치를 곱해 모두 더한 뒤 편향을 더한 값이다. 층 단위로는 z = Wx + b로 쓰며 W의 각 행이 뉴런 하나에 대응한다.

잠깐 확인 — x = [1, 2], w = [3, 4], b = 0이면 가중합 z는?

1×3 + 2×4 = 11이에요. 곱한 것을 모두 더하는 게 전부예요.

0-5. 기울기(경사)를 "산 내려가기"로

한 줄 정의

기울기(미분)는 "지금 서 있는 이 자리가 오르막인지 내리막인지, 얼마나 가파른지"를 알려 주는 숫자예요. 교수님은 "순간 기울기"라고 불렀어요.

학습은 손실(틀린 정도)이 가장 낮은 곳을 찾는 일이에요. 손실을 산의 높이라고 생각하면 학습은 "산에서 가장 낮은 골짜기까지 내려가기"예요.

비유 — 안개 낀 산

짙은 안개 때문에 산 전체는 안 보이고 발밑의 기울기만 느낄 수 있어요. 발밑이 오른쪽으로 내리막이면 오른쪽으로 한 걸음, 왼쪽으로 내리막이면 왼쪽으로 한 걸음 가요. 이걸 반복하면 골짜기에 도착해요.

기울기가 양수(+)면 오른쪽이 오르막이라서 값을 줄여야 하고, 음수(−)면 오른쪽이 내리막이라서 값을 늘려야 해요. 그래서 식이 w ← w − η × 기울기예요. 빼기 기호 하나가 "기울기의 반대 방향으로 간다"는 뜻을 모두 담고 있어요.

여기서 η(에타)는 학습률이에요. "한 걸음을 얼마나 크게 뗄까"를 정하는 숫자이고, 자세한 내용은 4장에서 다뤄요.

시험엔 이렇게 써요

경사하강은 손실의 기울기를 구해 그 반대 방향으로 가중치를 조금씩 이동시켜 손실을 줄여 나가는 방법이다.

잠깐 확인 — 기울기가 양수일 때 w는 커져야 할까요, 작아져야 할까요?

작아져야 해요. 양수는 오르막이라는 뜻이라서 내리막 쪽(값이 작은 쪽)으로 가요.

0-6. 로그와 지수 — "작을수록 크게 벌주는 함수"

3장의 Cross-Entropy(손실) 식에 −log가 나와요. 로그의 계산법은 몰라도 돼요. 시험은 로그 수치를 손으로 계산시키지 않고, 그래프 모양만 읽게 해요.

한 줄 정의

−log p는 "p가 1이면 벌점 0, p가 0에 가까워질수록 벌점이 급격히 커지는" 함수예요. 여기서 p는 정답에 준 확률이에요.

정답에 준 확률 p1.00.90.50.10.010에 가까움
벌점 −log p00.1050.6932.3034.605끝없이 커짐
비유 — 자신 있게 틀린 학생

"잘 모르겠다"며 찍어서 틀린 학생보다 "100% 확실하다"며 틀린 학생이 더 크게 혼나요. −log p는 자신 있게 틀릴수록 벌점이 폭증하는 이 규칙을 그대로 식으로 쓴 거예요.

같이 나오는 지수(e의 거듭제곱, eᶻ)도 알아 두세요. e는 약 2.718인 특별한 수예요.

eᶻ는 z가 0이면 1이고, z가 커질수록 훨씬 빠르게 커지며, z가 음수여도 항상 0보다 커요. Softmax가 이 성질을 이용해요.

시험엔 이렇게 써요

−log p는 정답 확률 p가 작아질수록 값이 급격히 커지는 곡선이라서, 정답에 낮은 확률을 준 예측일수록 큰 손실을 준다.

잠깐 확인 — 정답 확률이 0.9일 때와 0.1일 때 중 벌점이 더 큰 쪽은?

0.1일 때예요. 0.105와 2.303으로 약 22배 차이가 나요.

0-7. 시험에서 계산은 어디까지? 기호 읽는 법

교수님이 7주차 복습 시간에 직접 말한 범위예요. 시그모이드와 로그 값의 수치 손계산은 출제하지 않아요. 대신 정수로 끝나는 계산은 나와요.

나오는 계산예
파라미터 수784→256→10 이면 203,530 (2장)
step 수샘플 수 ÷ batch 크기를 올림
혼동행렬 지표"몇 나누기 몇", "몇 곱하기 몇" 정도

계산기는 필요 없다고 했어요. 곱셈은 시험지 여백에 쓰면 돼요.

이제 자주 보이는 기호를 한꺼번에 정리해 볼게요.

시험엔 이렇게 써요

객관식에서는 "파라미터 수, step 수, 혼동행렬 지표"처럼 정수로 끝나는 계산만 나오며, 시그모이드·로그의 수치 계산은 출제되지 않는다. 그래서 곱셈 몇 번과 나눗셈 한 번을 정확히 하는 연습이 우선이다.

잠깐 확인 — ŷ 기호가 가리키는 것은 정답일까요, 예측일까요?

예측이에요. 모자(^)가 씌워진 것은 모델이 계산한 값이고, 모자가 없는 y가 정답이에요.

이 장 3줄 요약
  • 머신러닝은 데이터로 모델 안의 숫자(w, b)를 고쳐 가며 배우는 일이고, 계산의 뼈대는 "곱하고 더하기(가중합)"예요.
  • 기울기는 발밑 경사이고, 학습은 기울기의 반대 방향으로 조금씩 내려가 손실이 가장 낮은 곳을 찾는 일이에요.
  • −log p는 정답 확률이 작을수록 벌점이 폭증하는 곡선이고, 시험은 수치 손계산 대신 정수 계산(파라미터 수·step 수·혼동행렬)을 내요.
