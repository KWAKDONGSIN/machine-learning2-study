MLP 구조와 파라미터 수 — 층을 쌓고 숫자를 세요

뉴런을 나란히 놓으면 층이 되고, 층을 이어 붙이면 MLP(다층 퍼셉트론)가 돼요. 시험에서 정수 계산으로 가장 확실하게 나오는 것이 "층 구성이 주어지면 편향을 포함한 전체 파라미터 수를 센다"예요. 이 장의 공식 하나를 확실히 잡으면 점수가 보장돼요.

2-1. 입력층·은닉층·출력층 — 층마다 하는 일은 같아요

한 줄 정의

MLP(Multi-Layer Perceptron, 다층 퍼셉트론)는 입력층과 출력층 사이에 은닉층이 1개 이상 있는 신경망이에요. 층마다 하는 일은 항상 "가중합 → 활성화"예요.

  • 입력층(input layer) — 데이터를 받는 곳이에요. 계산은 하지 않고 숫자를 넘겨줘요. 파라미터도 없어요.
  • 은닉층(hidden layer) — 중간에서 가중합과 활성화를 하는 층이에요. 우리는 입력과 출력만 보고 중간 계산은 안 보여서 "은닉(hidden)"이라고 불러요.
  • 출력층(output layer) — 마지막에 답을 내는 층이에요. 문제 유형에 맞춰 활성화 함수를 골라요(3장).
비유 — 식품 공장

원료를 넣는 입구(입력층), 눈에 안 보이는 가공 공정 여러 단계(은닉층), 완제품이 나오는 출구(출력층)라고 생각하세요. 각 공정은 앞 공정에서 받은 것을 섞고 가공해서 다음 공정에 넘겨요. 공정이 하는 일의 모양(가중합 → 활성화)은 매번 같아요.

순전파(forward propagation)는 입력을 층마다 통과시켜 출력을 계산하는 과정이에요. 층 하나는 이렇게 써요.

z⁽¹⁾ = W⁽¹⁾x + b⁽¹⁾, a⁽¹⁾ = f(z⁽¹⁾) ← 첫 번째 은닉층 z⁽²⁾ = W⁽²⁾a⁽¹⁾ + b⁽²⁾, a⁽²⁾ = f(z⁽²⁾) ← 두 번째 은닉층 z⁽ᴸ⁾ = W⁽ᴸ⁾a⁽ᴸ⁻¹⁾ + b⁽ᴸ⁾, ŷ = g(z⁽ᴸ⁾) ← 출력층

위 첨자 (1), (2)는 "몇 번째 층"이라는 표시일 뿐이에요. 앞 층의 출력 a가 다음 층의 입력이 돼요.

교수님은 "연산의 단위는 뉴런 하나가 아니라 층"이라는 점을 짚었어요. 은닉층의 활성화는 f(ReLU 등), 출력층의 활성화는 g(softmax 등)로 따로 써요.

시험엔 이렇게 써요

MLP는 입력층, 하나 이상의 은닉층, 출력층으로 구성되며, 각 층에서 가중합과 활성화를 반복하여 입력을 출력으로 변환한다. 이 과정을 순전파라고 한다.

잠깐 확인 — 은닉층이라고 부르는 이유는?

입력과 출력은 눈에 보이지만 중간 층의 계산은 밖에서 보이지 않기 때문이에요.

2-2. 단층 퍼셉트론 / MLP / DNN 구분

구분의 기준은 딱 하나, 은닉층이 몇 개인가예요.

이름은닉층풀 수 있는 문제
단층 퍼셉트론0개선형으로 나눌 수 있는 문제만 (XOR은 못 풀어요)
MLP1개 이상비선형 결정경계도 가능 (XOR 가능)
DNN(심층 신경망)2개 이상계층적 특징 학습 — 이미지·언어

"딥(deep)"의 뜻은 단순히 은닉층이 여러 개라는 거예요. 층이 깊어질수록 표현력은 커지지만, 학습은 어려워져요. 이유는 기울기 소실이라는 문제 때문이고, 교수님은 "문제가 있다는 정도만 알아 두라"고 했어요.

외우기 팁

그림을 보면 "입력과 출력 사이에 낀 층이 몇 개인가"를 세요. 0개면 단층, 1개 이상이면 MLP, 2개 이상이면 DNN이에요. 은닉층 1개는 MLP이면서 DNN은 아니에요.

시험엔 이렇게 써요

입력층과 출력층 사이의 은닉층이 없으면 단층 퍼셉트론, 1개 이상이면 MLP, 2개 이상이면 DNN이라고 한다. 단층 퍼셉트론은 선형 분리가 가능한 문제만 풀 수 있고, 은닉층이 있는 MLP는 비선형 결정경계도 표현할 수 있다.

잠깐 확인 — 입력 → 은닉(256) → 출력(10)인 네트워크는 MLP일까요, DNN일까요?

MLP예요. 은닉층이 1개뿐이라서 DNN(은닉층 2개 이상)은 아니에요.

2-3. 가중치 행렬의 크기 읽기 — W는 (이번 층 × 앞 층)

한 층의 계산은 z = Wx + b예요. 여기서 W의 크기가 시험에 나와요. 외울 문장은 이거 하나예요.

한 줄 정의

W⁽ˡ⁾의 크기 = (이번 층 뉴런 수 nₗ) × (앞 층 뉴런 수 nₗ₋₁)이고, 편향 b⁽ˡ⁾의 크기는 nₗ(이번 층 뉴런 수)예요.

이유는 이래요. 앞 층 뉴런 nₗ₋₁개가 이번 층 뉴런 nₗ개 각각에 모두 연결돼요.

이런 "모두 연결"을 완전 연결(fully connected) 또는 Dense 층이라고 불러요. 이번 층 뉴런 하나가 앞 층 숫자 nₗ₋₁개를 곱하는 가중치 한 줄(행)을 가져서, 행이 nₗ개, 열이 nₗ₋₁개인 표가 돼요.

층W의 크기b의 크기파라미터
입력(4) → 은닉(5)5 × 455×4 + 5 = 25
은닉(5) → 출력(3)3 × 533×5 + 3 = 18
합계43
외우기 팁

크기를 헷갈리면 곱셈이 되는지 확인하세요. W(5×4)에 x(4개)를 곱하면 "안쪽 숫자 4와 4가 같아서" 곱셈이 되고, 결과는 "바깥 숫자 5"개가 나와요. 그래서 W는 (이번 층) × (앞 층)이에요.

시험엔 이렇게 써요

l번째 층의 가중치 행렬 W⁽ˡ⁾는 (nₗ × nₗ₋₁) 크기이다. 앞 층의 nₗ₋₁개 뉴런이 이번 층의 nₗ개 뉴런 각각에 연결되기 때문이며, 편향 벡터 b⁽ˡ⁾는 뉴런마다 하나씩이라 크기가 nₗ이다.

잠깐 확인 — 앞 층 784개, 이번 층 256개일 때 W의 크기는?

(256, 784)예요. 이번 층 수가 앞(행)에, 앞 층 수가 뒤(열)에 와요.

2-4. 파라미터 수 세기 ★★ — 공식과 예제

한 줄 정의

한 층의 파라미터 수 = (앞 층 뉴런 수 × 이번 층 뉴런 수) + 이번 층 뉴런 수. 앞의 곱은 가중치 W의 개수이고, 뒤의 덧셈은 편향 b의 개수예요. 전체 파라미터 수는 층마다 구해서 모두 더해요.

교수님은 "각각의 전체 파라미터 수를 세는 것이 중요하다"고 7주차 복습 시간에 강조했어요. 시험에 확실히 나오는 정수 계산이에요. 파라미터는 학습으로 고쳐지는 숫자(w와 b)를 말해요.

비유 — 조절 손잡이 세기

각 뉴런에는 입력마다 하나씩 돌릴 수 있는 손잡이(가중치)와, 전체를 올리고 내리는 손잡이(편향) 하나가 달려 있어요. 파라미터 수는 이 신경망에 달린 손잡이를 전부 센 개수예요.

예제 1. 입력 4 → 은닉 5 → 출력 3

1층 4×5 + 5 = 25 2층 5×3 + 3 = 18 합계 25 + 18 = 43

예제 2. 입력 784 → 은닉 256 → 출력 10 (MNIST)

1층 784×256 + 256 = 200,704 + 256 = 200,960 2층 256×10 + 10 = 2,560 + 10 = 2,570 합계 200,960 + 2,570 = 203,530

예제 3. 입력 d → 은닉 h → 출력 K의 일반식은 (d·h + h) + (h·K + K)예요. 아이리스처럼 d = 4, h = 8, K = 3이면 다음과 같아요.

1층 4×8 + 8 = 32 + 8 = 40 2층 8×3 + 3 = 24 + 3 = 27 합계 40 + 27 = 67

예제 4. 은닉층이 2개인 784 → 128 → 64 → 10

1층 784×128 + 128 = 100,352 + 128 = 100,480 2층 128×64 + 64 = 8,192 + 64 = 8,256 3층 64×10 + 10 = 640 + 10 = 650 합계 100,480 + 8,256 + 650 = 109,386

시험에서 자주 틀리는 실수는 이 세 가지예요.

  • 편향을 빼먹는 것 — 곱셈 결과만 더하면 틀려요. 층마다 "+ 이번 층 뉴런 수"를 꼭 붙여요.
  • 입력층을 한 층으로 세는 것 — 입력층은 파라미터가 없어요. 층 "사이"마다 계산해요. 층이 3개면 계산은 2번, 4개면 3번이에요.
  • 활성화·Flatten·Dropout에 파라미터를 세는 것 — 이들은 모두 0이에요.
외우기 팁

곱셈이 큰 수일 때는 쪼개서 계산하세요. 784×256은 784×250 = 196,000에 784×6 = 4,704를 더해 200,704예요. 계산기는 필요 없고 시험지 여백에 쓰면 돼요.

시험엔 이렇게 써요

입력 784, 은닉 256, 출력 10인 MLP의 파라미터 수는 (784×256 + 256) + (256×10 + 10) = 200,960 + 2,570 = 203,530개이다. 층마다 가중치 수(앞 층×이번 층)와 편향 수(이번 층)를 더하고 전체 층을 합산한다.

잠깐 확인 — 입력 3 → 은닉 4 → 출력 2의 파라미터 수는?

(3×4 + 4) + (4×2 + 2) = 16 + 10 = 26개예요.

2-5. Keras 코드와 model.summary()에서 파라미터 읽기

강의 Chapter 3의 MNIST 실습 모델이 바로 784 → 256 → 10이에요. 코드를 한 줄씩 읽어 볼게요.

model = models.Sequential([ layers.Input(shape=(28,28)), layers.Flatten(), layers.Dense(256, activation='relu'), layers.Dropout(0.2), layers.Dense(10, activation='softmax') ]) model.summary()
코드 줄무슨 뜻파라미터
Input(shape=(28,28))입력은 28×28 이미지라고 선언해요0
Flatten()2차원 이미지를 784개짜리 한 줄로 펴요0
Dense(256, activation='relu')256개 뉴런의 완전 연결층. 가중합 → ReLU784×256 + 256 = 200,960
Dropout(0.2)학습할 때 뉴런 20%를 무작위로 꺼요0
Dense(10, activation='softmax')10개 클래스의 확률을 내는 출력층256×10 + 10 = 2,570

model.summary()를 실행하면 층마다 출력 모양과 파라미터 수가 표로 나와요. 결과는 다음과 같아요.

flatten (Flatten) (None, 784) 0 dense (Dense) (None, 256) 200,960 dropout (Dropout) (None, 256) 0 dense_1 (Dense) (None, 10) 2,570 Total params: 203,530

알아 둘 점이 세 가지 있어요.

  • (None, 784)의 None은 "한 번에 몇 장을 넣는지(batch)는 아직 안 정해졌다"는 뜻이에요. 파라미터와는 관계없어요.
  • Dropout은 파라미터를 버리는 게 아니에요. 학습할 때만 뉴런을 확률적으로 껐다 켜는 장치라서 파라미터는 0개예요.
  • 첫 Dense 층이 전체의 약 98.7%(200,960 ÷ 203,530)예요. 그래서 은닉 뉴런 수가 모델의 크기를 거의 정해요.

은닉 뉴런 수를 바꾸면 합계가 이렇게 달라져요. 강의자료 실험 결과와 같은 숫자예요.

은닉 뉴런 수1층 (784→h)2층 (h→10)합계
128100,4801,290101,770
256200,9602,570203,530
512401,9205,130407,050

은닉 수를 4배(128 → 512)로 늘리면 파라미터도 약 4배인데, 정확도는 0.4%p밖에 안 올랐어요. 크게 키워도 효과가 점점 줄어든다는(수확체감) 뜻이에요.

시험엔 이렇게 써요

Dense(in → out)의 파라미터 수는 in × out + out이고 Flatten과 Dropout은 0개이다. 784 → 256 → 10 모델의 Total params는 203,530이며, 은닉 유닛을 512로 바꾸면 (784×512 + 512) + (512×10 + 10) = 407,050이 된다.

잠깐 확인 — Dense(256)을 Dense(512)로 바꾸면 첫 Dense 층의 파라미터는? (입력 784)

784×512 + 512 = 401,408 + 512 = 401,920개예요. 강의자료 셀프체크 Q1이에요.

2-6. 연습 문제 — 직접 세어 보세요

종이에 식을 쓰고 풀어 본 뒤 답을 열어 보세요. 수십 번 보는 것보다 한 번 써 보는 것이 훨씬 오래가요.

연습 1 — 입력 10 → 은닉 20 → 출력 5

(10×20 + 20) + (20×5 + 5) = 220 + 105 = 325개예요.

연습 2 — 아이리스 분류기(특성 4개, 품종 3개)가 은닉층 없이 입력에서 바로 출력(softmax)으로 가면?

4×3 + 3 = 15개예요. 강의자료의 Softmax 회귀 모델이고, W는 4×3, b는 3개예요.

연습 3 — 784 → 256 → 128 → 10

(784×256 + 256) + (256×128 + 128) + (128×10 + 10) = 200,960 + 32,896 + 1,290 = 235,146개예요.

연습 4 — 784 → 64 → 10에서 W⁽¹⁾의 크기와 전체 파라미터 수는?

W⁽¹⁾는 (64, 784)이고, 전체는 (784×64 + 64) + (64×10 + 10) = 50,240 + 650 = 50,890개예요.

연습 5 — 파라미터가 많을수록 항상 좋은가요?

아니에요. 파라미터가 데이터에 비해 너무 많으면 과적합이 생기기 쉽고, 계산량도 늘어요. 효과가 점점 줄어드는 수확체감도 있어요.

시험엔 이렇게 써요

층 구성이 주어지면 층 사이마다 (앞 층 뉴런 수 × 이번 층 뉴런 수) + 이번 층 뉴런 수를 계산해 모두 더한다. 예를 들어 입력 3, 은닉 4, 출력 2이면 (3×4 + 4) + (4×2 + 2) = 26개이다.

이 장 3줄 요약
  • MLP는 입력층 + 은닉층(1개 이상) + 출력층이고 층마다 "가중합 → 활성화"를 반복해요. 은닉층 0개는 단층, 1개 이상은 MLP, 2개 이상은 DNN이에요.
  • W⁽ˡ⁾의 크기는 (이번 층 × 앞 층), b⁽ˡ⁾의 크기는 이번 층 뉴런 수이고, 편향은 뉴런마다 하나씩이에요.
  • 파라미터 수 = (앞 층 수 × 이번 층 수) + 이번 층 수를 층마다 구해 더해요. 784→256→10은 203,530이고 Flatten·Dropout은 0이에요.
