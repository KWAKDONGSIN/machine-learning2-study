혼동행렬과 평가지표 — 정확도 하나로는 보이지 않는 것

모델이 얼마나 잘 맞혔는지 점수 하나(정확도)로 말하면 속기 쉬워요. 이 장에서는 맞힌 것과 틀린 것을 네 칸에 나눠 담는 표(혼동행렬)를 읽고, 그 표로 정밀도·재현율·F1을 정수 계산으로 구하는 법을 익혀요. 시험에 반드시 나오고, 교수님이 "정답률이 안 좋다"고 한 부분이라 꼼꼼히 봐요.

5-1. 혼동행렬 — 맞음과 틀림을 네 칸에 담은 표 ★

혼동행렬(confusion matrix)은 모델의 예측과 실제 정답을 나란히 놓고 개수를 센 표예요. "어떤 것을 어떤 것으로 헷갈렸는지"가 한눈에 보여서 혼동(헷갈림)행렬이라고 불러요.

먼저 약속 하나가 있어요. 찾고 싶은 쪽을 양성(Positive), 나머지를 음성(Negative)이라고 불러요. 암 검사라면 "암이다"가 양성, 스팸 필터라면 "스팸이다"가 양성이에요. 좋고 나쁨이 아니라 "찾고 싶은 쪽"이라는 뜻이에요.

한 줄 정의

행 = 실제 정답, 열 = 모델의 예측. 대각선(TP, TN)은 맞힌 것, 대각선 밖(FN, FP)은 틀린 것이에요.

칸풀네임뜻 (암 검진으로)
TPTrue Positive실제로 암이고, 모델도 "암"이라고 함 → 정답
TNTrue Negative실제로 정상이고, 모델도 "정상"이라고 함 → 정답
FPFalse Positive실제로는 정상인데 "암"이라고 함 → 거짓 경보
FNFalse Negative실제로는 암인데 "정상"이라고 함 → 놓침
외우기 팁

글자를 둘로 쪼개서 읽어요. 뒤 글자(Positive/Negative)는 모델이 한 말이고, 앞 글자(True/False)는 그 말이 맞았는지예요. 그래서 FN은 "모델이 Negative라고 했는데(뒤 글자) 틀렸다(앞 글자)", 즉 실제로는 Positive였다는 뜻이에요. FP는 그 반대로 "모델이 Positive라고 했는데 틀림"이라서 실제는 Negative예요.

비유 — 양치기 소년과 늑대

마을 경비가 "늑대다!"라고 외치는 것이 양성 예측이에요. 늑대가 진짜 왔으면 TP, 안 왔는데 외치면 FP(거짓 경보)예요. 늑대가 왔는데 조용했다면 FN(놓침)이고, 아무 일 없어서 조용했다면 TN이에요.

왜 이렇게 나눌까요? 틀린 것도 두 종류라서 값이 달라요. 환자를 놓치는 것(FN)과 건강한 사람을 환자로 부르는 것(FP)은 결과가 완전히 달라서, 그냥 "틀린 개수"로 합치면 중요한 정보가 사라져요.

표를 그릴 때 행과 열을 반대로 그리는 책도 있어요. 이 수업(강의자료와 sklearn의 confusion_matrix)은 행 = 실제, 열 = 예측이에요. 시험에서도 이 기준으로 나와요.

시험엔 이렇게 써요

혼동행렬은 분류 모델의 예측과 실제 정답을 비교해 TP, TN, FP, FN으로 정리한 표이다. FP는 실제 음성을 양성으로 잘못 예측한 거짓 경보이고, FN은 실제 양성을 음성으로 잘못 예측한 놓침이다. (객관식 요령) 뒤 글자는 모델의 예측, 앞 글자는 그 예측이 맞았는지를 뜻한다.

잠깐 확인 — "FN"이 많다는 것은 어떤 오류가 많다는 뜻인가요?

실제 양성을 음성이라고 놓친 경우가 많다는 뜻이에요. 모델이 Negative라고 했는데(N) 틀렸으니(F) 실제는 양성이에요.

5-2. 네 가지 지표 — 분모가 전부예요 ★

혼동행렬의 숫자 네 개로 지표를 만들어요. 외울 것은 식이 아니라 분모에 무엇이 들어가는가예요. 교수님도 "단순 암기하지 말고 분모에 뭐가 들어가는지 알라"고 했어요.

지표식분모의 뜻
Accuracy
정확도		(TP + TN) / 전체전체 개수. 맞힌 것(대각선)의 비율
Precision
정밀도		TP / (TP + FP)모델이 "양성"이라고 한 것 전부 (예측 양성 = 열). 그중 진짜 양성의 비율
Recall
재현율		TP / (TP + FN)실제 양성 전부 (실제 양성 = 행). 그중 모델이 찾아낸 비율
F12·P·R / (P + R)정밀도와 재현율의 조화평균. 둘이 모두 높아야 높아요

교수님은 정밀도를 Precision, 재현율을 Recall이라고 한글과 영어를 모두 알아 두라고 했어요. 시험 보기에는 둘이 섞여서 나와요.

비유 — 물고기 잡기

바다에 진짜 물고기 50마리가 있고, 그물로 40개를 건졌는데 그중 30개가 진짜 물고기이고 10개는 쓰레기였어요. 정밀도는 건진 것 중 진짜 비율(30/40)이고, 재현율은 바다 전체 물고기 중 건진 비율(30/50)이에요.

그물을 아무 데나 크게 던지면 재현율은 오르지만 쓰레기가 늘어 정밀도가 떨어져요. 확실한 곳에만 던지면 정밀도는 오르지만 놓치는 물고기가 늘어 재현율이 떨어져요. 그래서 둘은 서로 줄다리기를 해요.

F1은 왜 평균이 아니라 조화평균일까요? 한쪽이 형편없으면 점수도 형편없게 만들려는 거예요. 정밀도 1.0, 재현율 0.1이면 단순 평균은 0.55라 괜찮아 보이지만, F1은 2·1.0·0.1 / 1.1 ≈ 0.18로 확 떨어져요. 어느 한쪽만 높이는 꼼수가 안 통해요.

외우기 팁

정밀도의 분모는 "예측한 양성"(열), 재현율의 분모는 "실제 양성"(행)이에요. 둘 다 위(분자)는 TP로 같고, 아래만 FP와 FN으로 달라요. "Precision의 분모에는 Predicted positive, Recall의 분모에는 Real positive"라고 첫 글자로 기억해도 좋아요.

시험엔 이렇게 써요

정밀도(Precision)는 양성으로 예측한 것 중 실제 양성의 비율 TP/(TP+FP)이고, 재현율(Recall)은 실제 양성 중 양성으로 맞힌 비율 TP/(TP+FN)이다. F1은 두 값의 조화평균 2PR/(P+R)이다. (객관식 요령) 분모가 "예측 양성 전체"인지 "실제 양성 전체"인지부터 확인한다.

잠깐 확인 — 정밀도와 재현율은 분자가 같은데 분모는 각각 무엇인가요?

분자는 둘 다 TP예요. 정밀도의 분모는 TP+FP(양성이라고 예측한 전부), 재현율의 분모는 TP+FN(실제 양성 전부)이에요.

5-3. 계산 연습 — 정수로 끝나는 문제 ★

시험에서는 계산기를 못 써요. 하지만 시그모이드나 로그 같은 어려운 계산은 나오지 않고, "몇 나누기 몇", "몇 곱하기 몇" 수준의 정수 계산만 나온다고 교수님이 말했어요. 분수로 두고 약분하면 쉬워요.

연습 1. 200명 검사 결과가 TP=30, FP=10, FN=20, TN=140이에요.

지표계산값
정확도(30+140)/200 = 170/2000.85
정밀도30/(30+10) = 30/400.75
재현율30/(30+20) = 30/500.6
F12·0.75·0.6 / (0.75+0.6) = 0.9/1.35 = 2/3약 0.67

F1은 식 하나를 더 알면 빨라요. F1 = 2TP / (2TP + FP + FN)이에요. 여기에 넣으면 60/(60+10+20) = 60/90 = 2/3로 바로 나와요(이 식은 참고용이고, 시험에서는 위 정의대로 써도 돼요).

연습 2. 교수님 슬라이드의 검진 예시예요. 1,000명 중 환자 100명, TP=90, FN=10, FP=90, TN=810이에요.

  • 정확도 = (90+810)/1000 = 0.9
  • 정밀도 = 90/(90+90) = 90/180 = 0.5
  • 재현율 = 90/(90+10) = 90/100 = 0.9
  • F1 = 2·0.5·0.9 / (0.5+0.9) = 0.9/1.4 ≈ 0.64

정확도가 90%인데 정밀도는 겨우 0.5예요. 이 예시가 5-4의 핵심이에요.

연습 3 (문장으로 주어질 때). "실제 환자는 8명이다. 모델은 10명을 양성이라고 했고, 그중 6명이 진짜 환자였다. 정밀도와 재현율은?"

문장을 표로 바꾸는 게 첫 단계예요. "양성이라고 한 10명" = TP+FP이고 그중 진짜 6명 = TP이므로 FP=4예요. "실제 환자 8명" = TP+FN이므로 FN=2예요.

  • 정밀도 = 6/10 = 0.6
  • 재현율 = 6/8 = 0.75
시험엔 이렇게 써요

(계산형) 먼저 TP, FP, FN, TN을 문제에서 뽑아 적고, 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN)에 대입한다. 예) TP=6, FP=4, FN=2이면 정밀도 6/10 = 0.6, 재현율 6/8 = 0.75이다.

잠깐 확인 — TP=40, FP=10, FN=40, TN=110일 때 정밀도와 재현율은?

정밀도는 40/(40+10) = 40/50 = 0.8, 재현율은 40/(40+40) = 40/80 = 0.5예요. 정확도는 (40+110)/200 = 0.75이고요.

5-4. 정확도의 함정 — 불균형 데이터와 "모두 음성" 모델 ★

병에 걸린 사람이 전체의 10%뿐인 상황(유병률 10%)을 생각해 봐요. 그런데 어떤 바보 모델이 환자를 한 번도 찾지 않고 무조건 "음성(정상)"이라고만 답해요.

1,000명 (환자 100명)예측 양성예측 음성
실제 양성 (100)TP = 0FN = 100
실제 음성 (900)FP = 0TN = 900
  • 정확도 = (0+900)/1000 = 0.9, 겉보기에는 아주 훌륭해요.
  • 재현율 = 0/(0+100) = 0, 환자를 단 한 명도 못 찾았어요.
  • 정밀도 = 0/0이라 계산할 수 없어요(양성이라고 한 적이 없으니까요). 보통 0으로 처리해요.

유병률이 1%라면 같은 바보 모델의 정확도는 0.99까지 올라가요. 왜 이럴까요? 정확도는 "맞힌 개수 ÷ 전체"라서, 숫자가 많은 쪽(음성)을 다 맞히기만 해도 높게 나와요. 클래스 수가 한쪽으로 쏠린 것을 클래스 불균형이라고 해요.

비유 — 도둑 없는 마을

도둑이 하루 100명 중 1명뿐인 마을에서 "도둑은 한 명도 없다"고만 말하는 경비원은 99%를 맞혀요. 하지만 진짜 도둑은 한 번도 못 잡아요. 쓸모없는 경비원인데 점수만 높은 거예요.

그래서 실무 보고서에는 정확도만 쓰지 않고 혼동행렬과 정밀도·재현율을 함께 붙여요. 교수님은 "정확도만 적으면 듣는 사람이 뭘 숨기냐고 의심한다"고 했어요.

시험엔 이렇게 써요

유병률이 낮은 불균형 데이터에서는 모든 샘플을 음성으로 예측하는 모델도 정확도가 높게 나온다(유병률 10%이면 0.9). 그러나 재현율은 0이므로 정확도만으로 성능을 판단할 수 없고, 혼동행렬과 정밀도·재현율을 함께 확인해야 한다.

잠깐 확인 — 유병률 5%인 병에서 "모두 음성"이라고 답하는 모델의 정확도와 재현율은?

정확도는 0.95, 재현율은 0이에요. 환자 5%를 하나도 못 찾았어도 정상 95%를 다 맞혔으니 정확도가 높게 나와요.

5-5. 3×3 혼동행렬 — 클래스 하나씩 "양성 대 나머지" ★

클래스가 셋 이상이면 표도 3×3으로 커져요. 방법은 간단해요. 지표를 알고 싶은 클래스 하나를 양성으로, 나머지를 전부 합쳐 음성으로 보면 2×2 표가 클래스마다 하나씩 나와요. 이것을 "양성 대 나머지"라고 불러요.

핵심은 행과 열을 구분하는 거예요.

알고 싶은 것어디를 보나계산
TP그 클래스의 대각선 칸(클래스 X, 클래스 X) 칸
FN (놓침)그 클래스의 행에서 대각선을 뺀 나머지실제 X인데 다른 것으로 예측
FP (거짓 경보)그 클래스의 열에서 대각선을 뺀 나머지실제는 다른 것인데 X로 예측
정밀도열 합이 분모TP ÷ 그 열의 합
재현율행 합이 분모TP ÷ 그 행의 합

행(실제)에서 가로로 읽으면 "이 클래스가 어디로 새는가"가 보이고, 열(예측)에서 세로로 읽으면 "이 예측에 무엇이 섞였는가"가 보여요.

예제 A — 교수님 슬라이드의 붓꽃 분류. 테스트 38개의 결과예요(행 = 실제, 열 = 예측).

실제 \ 예측setosaversicolorvirginica행 합
setosa111012
versicolor09413
virginica021113
열 합11121538
  • 정확도 = 대각선 합 / 전체 = (11+9+11)/38 = 31/38 ≈ 0.816
  • versicolor 정밀도 = 9 / (열 합 12) = 0.75 (FP = 열의 나머지 1+2 = 3)
  • versicolor 재현율 = 9 / (행 합 13) ≈ 0.69 (FN = 행의 나머지 0+4 = 4)
  • virginica는 재현율 11/13 ≈ 0.85인데 정밀도는 11/15 ≈ 0.73이에요. versicolor를 virginica로 4개나 잘못 부른 탓이에요.

예제 B — 고양이·개·토끼 (직접 풀어 봐요).

실제 \ 예측고양이개토끼
고양이5055
개103010
토끼5520

"개의 정밀도와 재현율은?"이라는 문제라면, 개 열은 5+30+5 = 40이고 개 행은 10+30+10 = 50이에요. 정밀도는 30/40 = 0.75, 재현율은 30/50 = 0.6이에요.

잠깐 확인 — 위 표에서 토끼의 정밀도와 전체 정확도는?

토끼 열의 합은 5+10+20 = 35이므로 정밀도는 20/35 = 4/7 ≈ 0.57이에요. 전체 정확도는 대각선 합 (50+30+20) = 100을 전체 140으로 나눈 100/140 ≈ 0.71이에요.

예제 C — 슬라이드의 7개 샘플 코드. 실제 [0,1,2,2,0,1,2], 예측 [0,0,2,1,0,2,2], 클래스 이름 A, B, C예요. 짝을 지어 세면 이런 표가 나와요.

실제 \ 예측ABC
A200
B101
C012
  • 정확도 = (2+0+2)/7 = 4/7 ≈ 0.571
  • B의 재현율 = 0/(1+0+1) = 0 (B 두 개를 모두 못 맞힘)
  • C의 정밀도 = 2/(0+1+2) = 2/3 (C라고 한 3개 중 B가 하나 섞임)

파이썬의 classification_report는 이 계산을 클래스마다 해서 정밀도·재현율·F1·support(그 클래스의 실제 개수 = 행 합)를 한 표로 보여 줘요.

외우기 팁

3×3 문제는 세 단계로 풀어요. ① 구하려는 클래스의 대각선 칸을 TP로 잡는다. ② 정밀도면 세로(열) 합, 재현율이면 가로(행) 합을 구한다. ③ TP를 그 합으로 나눈다. 행과 열을 헷갈릴 때는 "행 = 실제, 열 = 예측"을 먼저 써 두고 시작해요.

시험엔 이렇게 써요

다중 클래스에서는 클래스마다 해당 클래스를 양성, 나머지를 음성으로 놓고 지표를 계산한다. 특정 클래스의 정밀도는 대각선 값을 그 열(예측)의 합으로, 재현율은 대각선 값을 그 행(실제)의 합으로 나눈다. 정확도는 대각선 합을 전체 개수로 나눈다.

5-6. 어떤 오류가 더 비싼가 — 지표와 임계값 고르기 ★

FN과 FP는 틀린 정도가 같아도 값(비용)이 달라요. 어느 쪽이 더 아픈지에 따라 우선해서 볼 지표가 달라져요. 교수님은 이것을 "되게 실무적인 포인트"라고 했어요.

상황더 아픈 오류우선 지표와 이유
암 검진FN (환자를 놓침)재현율(Recall) 우선. 놓치면 생명이 위험하고, 거짓 경보(FP)는 재검사로 감당할 수 있어요.
스팸 차단FP (정상 메일을 스팸으로 차단)정밀도(Precision) 우선. 중요한 메일을 못 보는 것이 스팸 하나 받는 것보다 아파요.
부정 거래둘 다 비쌈, 그런데 부정 거래가 0.1%로 아주 드묾F1 + 임계값 조정. 정확도는 무의미(모두 정상이라 해도 99.9%)해요.
비유 — 교수님의 주식 비유

모델이 "산다(Yes)"고 하면 우리는 돈을 넣어요. 틀리면(FP) 진짜 손실이 나요. 반대로 모델이 "안 산다(No)"고 했는데 사실 올랐다면(FN) 돈을 번 기회를 놓친 것이라 손실은 안 나고 기회비용만 생겨요. 그래서 "양성이라고 말하는 순간 자원을 쓰는" 문제에서는 정밀도를 중요하게 봐요.

임계값(threshold)은 모델이 낸 확률이 몇 이상이면 "양성"이라고 부를지 정하는 기준선이에요. 보통은 0.5이지만 비용에 맞춰 옮겨요.

  • 임계값을 낮추면 (예 0.5 → 0.3) 양성 판정이 늘어서 재현율은 오르고 정밀도는 내려가요. 암 검진처럼 놓치면 안 될 때 써요.
  • 임계값을 높이면 (예 0.5 → 0.9) 확실할 때만 양성이라고 해서 정밀도는 오르고 재현율은 내려가요. 스팸 차단처럼 거짓 경보가 아플 때 써요.
  • 확률이 애매할 때는 자동으로 결정하지 않고 사람이 검토하도록 보류하는 방법도 실무에서 써요.

왜 정확도가 아니라 비용으로 정할까요? 임계값을 옮기면 정확도는 거의 그대로여도 FN과 FP의 개수가 서로 바뀌기 때문이에요. 어느 쪽 개수가 줄어야 이득인지는 비용이 정해요.

주관식 대비 — "문제 상황 → 출력층·지표·임계값·전처리" 답 쓰는 틀

예) "환자 사진으로 암 여부를 판정하는 모델을 만든다. 환자는 전체의 2%다."

  • 출력층 — 결과가 암/정상 두 가지(이진)이므로 출력 뉴런 1개, 활성화 sigmoid, 손실 binary cross-entropy
  • 지표 — 불균형(2%)이라 정확도는 무의미하고, 놓침(FN)이 치명적이므로 재현율을 우선하며 혼동행렬과 정밀도를 함께 보고
  • 임계값 — 0.5보다 낮춰(예 0.3) 재현율을 높이고, 늘어난 거짓 경보는 재검사로 처리
  • 전처리 — 입력 값을 같은 크기로 맞추는 표준화(평균 0, 표준편차 1)나 0~1 정규화를 하되, 기준값은 학습 데이터로만 계산해서(테스트 정보가 새지 않게) 테스트에도 그대로 적용
시험엔 이렇게 써요

암 검진은 환자를 놓치는 FN의 비용이 크므로 재현율을 우선하고 임계값을 낮춘다. 스팸 차단은 정상 메일을 막는 FP의 비용이 크므로 정밀도를 우선한다. 부정 거래처럼 양성이 극히 드문 경우는 정확도가 무의미하므로 F1과 임계값 조정으로 평가한다. (이유) 두 오류의 비용이 다르면 정확도 하나로는 모델을 선택할 수 없기 때문이다.

잠깐 확인 — 임계값을 0.5에서 0.3으로 낮추면 정밀도와 재현율은 각각 어떻게 되나요?

양성이라고 부르는 경우가 늘어나서 재현율은 오르고 정밀도는 내려가는 것이 보통이에요. 놓침은 줄고 거짓 경보는 늘어요.

  • ① 재현율
  • ② 정밀도
  • ③ 학습 손실
  • ④ epoch 수
정답 보기

②예요. 정상 메일을 스팸이라고 하는 것은 FP이고, FP를 줄이는 지표가 정밀도예요.

이 장 3줄 요약
  • 혼동행렬은 행 = 실제, 열 = 예측이고, TP·TN은 맞힘, FP는 거짓 경보, FN은 놓침이에요(뒤 글자는 예측, 앞 글자는 맞았는지).
  • 정밀도 = TP/(TP+FP)로 분모는 예측 양성(열), 재현율 = TP/(TP+FN)으로 분모는 실제 양성(행)이고, 정확도는 대각선 합 / 전체, F1은 둘의 조화평균이에요.
  • 불균형 데이터에서는 "모두 음성" 모델도 정확도가 높으니 혼동행렬과 P/R을 함께 보고, 암 검진은 재현율, 스팸은 정밀도, 부정 거래는 F1과 임계값으로 비용에 맞춰 골라요.
