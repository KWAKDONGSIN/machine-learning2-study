B 코스 — 오늘 이것만

어려운 건 다 뺐어요. 핵심 10개 + 약어 10개 + 숫자 6개 + 서술형 4개만 보면 돼요. 약 1시간이에요. 위에서부터 차례로 읽으세요.

B 받는 법

① 객관식에서 정수 계산(파라미터 수 · step 수 · 혼동행렬)을 맞힌다 ② 단답은 빈칸 철자를 그대로 쓴다 ③ 주관식은 아래 "시험엔 이 한 문장"을 이어서 빈칸 없이 쓴다. 이 셋이면 B예요.

먼저 큰 그림 한 줄

이 과목은 결국 이거예요. 뉴런을 쌓아 신경망을 만들고, 틀린 만큼 고쳐서 학습시키고, 너무 외우지 않게 막는다.

시험지 여백에 먼저 쓰기

입력 → 가중합 → 활성화 → (층 반복) → Softmax → 손실 → 기울기 → w 고치기

읽는 요령 — 점수 매기고(가중합) → 걸러 내고(활성화) → 확률로 바꾸고(Softmax) → 채점하고(손실) → 틀린 만큼 고친다(경사하강). 이걸 계속 반복하는 것이 학습이에요.

꼭 알아야 할 10개

1. 뉴런 하나와 편향

뉴런은 성적 환산기와 같아요. 과목마다 점수에 가중치를 곱해 모두 더하고(가중합), 보너스 점수(편향)를 더한 뒤, 합격선을 넘는지 걸러 내요(활성화 함수).

편향은 직선의 절편처럼 선을 위아래로 옮겨 주는 값이에요. 없으면 선이 반드시 원점을 지나야 해서 표현력이 줄어요. 편향은 층 전체에 하나가 아니라 뉴런마다 하나씩 있어요.

시험엔 이 한 문장

뉴런은 입력에 가중치를 곱해 모두 더하고 편향을 더한 가중합 z = wᵀx + b에 활성화 함수를 적용해 a = σ(z)를 출력한다. 선형회귀와 다른 점은 활성화 함수뿐이고, 편향은 결정경계를 평행 이동시킨다.

확인 — 뉴런이 8개인 층의 편향은 몇 개?

뉴런마다 하나씩이라 8개예요.

2. MLP와 파라미터 수 ★정수 계산

뉴런을 한 줄로 세운 것이 층이고, 층을 이어 붙인 것이 MLP예요. 입력층 → 은닉층 → 출력층이고, 은닉층이 1개 이상이면 MLP, 2개 이상이면 DNN이에요.

파라미터 수는 층마다 입력 × 출력 + 출력이에요. 마지막 "+ 출력"은 뉴런마다 하나인 편향이에요. Flatten과 Dropout은 학습할 값이 없어서 0개예요.

계산해 보기

784 → 256 → 10이면 (784×256+256) + (256×10+10) = 200,960 + 2,570 = 203,530개예요.

시험엔 이 한 문장

Dense 층의 파라미터 수는 입력 수 × 출력 수 + 출력 수(편향)이며 Flatten · Dropout은 0이다. 784 → 256 → 10 모델의 Total params는 203,530이다.

확인 — 입력 4 → 은닉 5 → 출력 3의 파라미터 수는?

(4×5+5) + (5×3+3) = 25 + 18 = 43개예요.

출력층은 문제 유형이 정해 줘요. 뉴런 수 · 활성화 · 손실이 한 세트로 움직여요.

여러 개 중 하나 (숫자 0~9)KSoftmaxCategorical Cross-Entropy (정수 라벨이면 sparse)

하나만 정답인 K클래스 분류는 뉴런 K개 · Softmax · Categorical Cross-Entropy를 쓰고, 정답이 여러 개일 수 있는 멀티라벨은 뉴런 K개 · Sigmoid · Binary Cross-Entropy를 쓴다.

확인 — 영화에 장르 태그를 여러 개 붙이는 모델의 출력층은?

장르 수만큼의 Sigmoid 뉴런과 Binary Cross-Entropy예요. Softmax는 하나만 고르는 용도예요.

4. Softmax와 Cross-Entropy

Softmax는 점수를 합이 100%인 퍼센트로 바꿔 줘요. 점수에 같은 수를 더해도 결과는 같고, 점수를 키우면 1등이 더 확신을 가져요. 하지만 0.9가 실제로 90% 맞는다는 보장은 없어요.

Cross-Entropy는 채점이에요. 정답 확률이 낮을수록 벌점이 커지고, 자신 있게 틀릴수록 벌점이 급격히 커져요. 둘을 합치면 출력층 기울기는 예측 − 정답(ŷ − y) 한 줄이에요.

시험엔 이 한 문장

Softmax는 로짓을 합이 1인 확률 분포로 바꾸고, Cross-Entropy는 L = −log(정답 확률)로 채점하여 자신 있게 틀릴수록 벌점이 급격히 커진다. 둘을 함께 미분하면 출력층 기울기는 ŷ − y이다.

확인 — 정답 확률을 0.9로 준 것과 0.1로 준 것 중 손실이 큰 쪽은?

0.1로 준 쪽이에요.

5. 경사하강과 학습률

학습은 안개 낀 산에서 내려오기와 같아요. 발밑의 기울기를 보고 반대쪽으로 한 걸음씩 가요. 한 걸음의 크기가 학습률 η이고, 식은 w ← w − η·∂L/∂w예요.

  • 걸음이 너무 작으면 개미걸음이라 손실이 아주 천천히 줄어요 → 올려요.
  • 걸음이 너무 크면 골짜기를 건너뛰어 손실이 튀거나 NaN이 돼요 → 내려요.
시험엔 이 한 문장

학습률이 너무 작으면 손실이 매우 느리게 줄어 학습률을 올리고, 너무 크면 손실이 튀거나 NaN이 되며 발산하므로 학습률을 낮춘다.

확인 — 학습률을 10배 올렸더니 loss가 NaN이 됐어요. 어떻게?

학습률을 낮춰요. 보폭이 너무 커서 발산한 거예요.

6. 혼동행렬과 Precision · Recall ★정답률 낮은 단골

도둑 잡기로 생각해요. 이름의 앞 글자(True/False)는 맞았나, 뒷글자(Positive/Negative)는 뭐라고 예측했나예요. FN은 "음성이라고 했는데 틀림" 곧 놓친 도둑, FP는 "양성이라고 했는데 틀림" 곧 억울한 사람이에요.

  • Precision = TP / (TP + FP). 분모는 도둑이라고 지목한 사람 전부.
  • Recall = TP / (TP + FN). 분모는 진짜 도둑 전부.
  • 행 = 실제, 열 = 예측. 대각선이 맞힌 칸.
계산해 보기

TP = 30, FP = 10, FN = 20이면 Precision = 30/40 = 0.75, Recall = 30/50 = 0.6이에요.

시험엔 이 한 문장

Precision은 양성이라고 예측한 것 중 진짜 양성의 비율이고 Recall은 진짜 양성 중 찾아낸 비율이다. 암 검진은 놓침(FN)이 치명적이어서 Recall을, 스팸 차단은 정상 메일을 막는 FP가 아파서 Precision을 우선한다.

확인 — 환자가 10%인데 "모두 정상"이라고 답하면 정확도는?

90%예요. 하지만 Recall은 0이라서 정확도만 보면 속아요.

7. 활성화 함수

활성화 함수가 없으면 층을 100개 쌓아도 직선 하나와 같아요(선형 ∘ 선형 = 선형). 곧은 막대기를 아무리 이어 붙여도 곧은 막대기인 것과 같아요. 중간에 꺾는 관절을 끼워야 해요.

함수그래프 한마디범위 · 기울기
SigmoidS자(0, 1). 기울기 최대 0.25라 층을 지나면 사라짐
TanhS자, 원점 대칭(−1, 1)
ReLU음수는 0, 양수는 직선양수 기울기 1, 음수 0. 은닉층의 기본
시험엔 이 한 문장

활성화 함수가 없으면 선형 ∘ 선형 = 선형이라 층을 쌓는 의미가 사라진다. ReLU는 max(0, x)로 양수 구간의 기울기가 1이어서 시그모이드(σ′ ≤ 0.25)보다 기울기 소실이 적다.

확인 — 음수는 0, 양수는 그대로 통과시키는 그래프는?

ReLU예요.

8. 과적합과 처방 ★시험에 반드시

과적합은 기출문제만 통째로 외운 학생이에요. 연습 문제(학습)는 만점인데 새 문제(검증)는 못 풀어요. 그래서 학습 곡선은 항상 학습과 검증 두 줄을 같이 그려요.

곡선이름처방
학습 ↓ · 검증은 다시 ↑ (간격 벌어짐)과적합검증 손실 최소에서 조기 종료, Dropout, L2, 데이터 증강
둘 다 높은 채 정체과소적합유닛 · 층 늘리기, 학습률 · epoch 올리기
둘 다 내려가 간격 좁음적절그 지점 저장
손실이 튀고 NaN학습률 과대학습률 낮추기
시험엔 이 한 문장

과적합은 학습 데이터에는 잘 맞지만 새 데이터에서는 성능이 떨어지는 현상으로, 학습 손실은 내려가는데 검증 손실이 다시 올라 간격이 벌어진다. 검증 손실 최소에서 조기 종료하고 Dropout, L2, 데이터 증강으로 완화한다.

확인 — 학습 손실 ↓, 검증 손실 ↑ 이면?

과적합이에요.

10. batch · epoch · step과 EarlyStopping ★정수 계산

문제집 55,000문제를 한 바퀴 다 푸는 것이 1 epoch이에요. 한 번에 128문제씩 풀고 채점해서 고치는 것이 1 step이고요. 그러면 1 epoch = 55,000 ÷ 128 = 429.7 → 올림해서 430 step이에요(로그의 430/430).

EarlyStopping은 최고 기록을 세운 뒤 patience번 연속으로 못 깨면 멈추는 규칙이에요. restore_best_weights=True면 최고였던 때의 모델로 되돌려요.

시험엔 이 한 문장

1 epoch의 step 수는 ⌈학습 샘플 수 / batch_size⌉이다. patience=3이고 epoch 7에서 최고였다면 10 epoch 끝에 멈추고 restore_best_weights=True이므로 epoch 7의 가중치가 남는다.

확인 — 20,000개, batch_size 256이면 1 epoch은 몇 step?

20,000 ÷ 256 = 78.125이고 올림해서 79 step이에요.

서술형 4개 — 이것만 연습

가리고 종이에 한 번씩 써 보세요. 위 "시험엔 이 한 문장"을 이어 붙이면 답이 돼요.

1. 학습 손실은 계속 줄고 검증 손실은 epoch 6부터 다시 오른다. 현상 · 근거 · 처방을 쓰시오.

과적합이다. 학습 손실은 계속 감소하는데 검증 손실은 epoch 6 이후 증가하고 두 곡선의 간격이 벌어지기 때문이다. 모델이 학습 데이터를 외워 새로운 데이터에 일반화하지 못한다는 뜻이다. 검증 손실 최소 지점에서 EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True)으로 멈추고 Dropout, L2, 데이터 증강으로 완화한다.

2. 학습률이 다른 세 곡선(A 아주 느림, B 적절, C 튀다가 NaN)을 진단하시오.

A는 학습률이 너무 작아 손실이 매우 느리게 줄어드므로 학습률을 올린다. B는 빠르게 줄다가 평평해지므로 적절하다. C는 학습률이 너무 커서 최솟값을 건너뛰어 손실이 커지고 발산(NaN)하므로 학습률을 낮춘다. 경사하강 w ← w − η·∂L/∂w에서 η가 한 번에 움직이는 크기를 정한다.

3. 환자 10%인 암 검진 신경망의 출력층 · 지표 · 임계값을 쓰시오.

이진 분류이므로 출력 뉴런 1개 · Sigmoid · Binary Cross-Entropy를 쓴다. 모두 음성이라 해도 정확도가 90%가 되는 함정이 있으므로 정확도 대신 암을 놓치는 FN이 치명적임을 고려해 Recall을 우선하고 Precision과 혼동행렬을 함께 본다. 임계값은 0.5보다 낮춰 양성 판정을 늘리고, FP는 재검사로 감당한다.

4. 은닉층에 활성화 함수가 필요한 이유와 ReLU를 쓰는 이유를 쓰시오.

활성화 함수가 없으면 선형 ∘ 선형 = 선형이라 층을 100개 쌓아도 선형 분류기 하나와 같아진다. 비선형 활성화를 넣어야 층을 쌓는 의미가 생긴다. ReLU는 양수 구간의 기울기가 1이라 곱해도 줄지 않아, σ′ ≤ 0.25인 시그모이드보다 기울기 소실이 적고 계산도 간단하다.
